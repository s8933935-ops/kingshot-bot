【初心者歓迎】専門用語・計算式・指標の活かし方ガイド

ゲーム内の「総戦力（Power）」は 兵士をたくさん抱えるだけで簡単に水増しできる ため、総戦力だけで砲台や駐屯を決めると「見た目ほど強くない部隊」が主力拠点を溶かしてしまいます。そこで本ポータルでは、MightPulse（秘境試練6塔 ＋ 移民スコア ＋ 火炉Lv） を使い、誰が見ても納得できるよう 「1兵あたりの強さ（質）」と「動員できる兵隊量（余裕度）」 を5つの指標に分解して算出しています。

① TG(火炉) — 真金世代ティア TG1 〜 TG8
一言イメージ：兵隊の世代ランク（装備・基礎ステータスの土台）。
火炉Lv（Stove Lv）60〜70 が真金兵士 TG6〜TG8 に該当します。同じ10万兵でも TG8 と TG6 では基礎耐久と攻撃力に明確な世代差が出ます。
TG = clip(floor((火炉Lv - 30) / 5), 1, 8)
・Lv.60〜64 ＝ TG6 ｜ Lv.65〜69 ＝ TG7 ｜ Lv.70 ＝ TG8
・混入リスク目安 EGC_M ＝ 推定兵力 × (TG / 8)² （TG6は0.5625倍目安※モデル換算）
🎯 実戦での活かし方：駐屯拠点には定員15名制限があるため、SGRは 班①②のTG8精鋭8名を主力拠点へ完全集中 させます。GODはTG8が22名・TG6以下ゼロのため、SGRがTG6以下（12名）を主力へ混ぜると耐久効率が急落します。空き枠は班③(TG7)で一時補助し、TG8着弾で即交代（「ダンス」）を徹底しましょう。
② 戦闘質 PCS — 純粋戦闘スコア 0 〜 1,000 点
一言イメージ：「兵数を抜いた1兵あたりの純粋な強さ（砲台向き度）」。
護符・領主装備・英雄・研究・ペットから算出しており、兵が増えても下がらず、兵がゼロでも高い数値が出ます。600点以上（特に700点超）が主砲・駐屯リーダー候補です。
1) 秘境試練6塔を各上限 CAP で0〜1に正規化（桁差バイアス除去）
CAP = {護符CC:400, 装備MF:440, 研究KN:320, ペットFoL:340, 英雄Col:800, 総合RS:840}
2) 実戦重み合成 Q_core = 0.26×CC + 0.20×Col + 0.18×MF + 0.14×KN + 0.14×RS + 0.08×FoL
3) 移民スコアの火炉倍率を除算中立化（TC=min(Stove,70), wps=Mig/TC+2226）し 12% のみ統合
PCS = 1000 × clip(0.88 × Q_core + 0.12 × clip(wps/42000, 0, 1), 0, 1)
🎯 実戦での活かし方：集結・駐屯は「リーダー1人の倍率」が全員の兵に乗ります。SGRは Top 4 平均 PCS 830.5 vs GOD 724.5（+106.0点圧倒）。一方で #5〜10（578.7 vs 662.5）・#11+（438.7 vs 582.4）はGODが厚いため、必ずTop4が頭を張る局地戦へ持ち込むことが勝利の絶対条件です。
③ 合流 Join — 乗る時専用スコア 0 〜 1,000 点
一言イメージ：「自分が砲台の集結・駐屯へ合流（乗る）ときの貢献度」。
自分が合流側（ジョイナー）に回る時は、自分の研究や領主装備は戦闘に使われず、「一番左（Slot 1）の英雄スキル」と「送る兵のTG」 だけが戦場に効きます。
PCS_joiner = 1000 × (0.45×n_Col[英雄] + 0.15×n_RS[総合] + 0.10×n_CC + 0.05×n_MF + 0.25×(TG / 8))
※英雄・総合塔・TG世代の比重 85% で合流適正を評価
🎯 実戦での活かし方：戦闘質 PCS が500台でも TG8 × 英雄育成（Join 642〜674） の高い班②（ROCK / ネプチューンマン / ぐるぐる）に加え、班①の リョ(942)・レッサー(881)・だりゅ(838)・Hinata(830)・ルーク(741) が相互合流することで最高火力を引き出せます。
④ 推定兵力（Troop Power） 単位：M（百万戦力）
一言イメージ：「総戦力から建物・研究などの固定戦力を引き算した、いま動く兵隊の数」。
王城戦や直近の戦闘で兵を消耗している場合、総戦力（Power）は高く見えても推定兵力（Troop）が小さく出ます。
1) 固定ベース戦力（冪乗則モデル）：BasePower_M = 5.79 × (wps ^ 0.318)
※高戦力帯で兵枯渇と誤認しないよう下側包絡線で非線形推定
2) 推定兵力：TroopPower_M = max(総戦力M - BasePower_M, 0)
3) 兵比率 phi = TroopPower_M / 総戦力M
🎯 実戦での活かし方：推定総兵力は SGR 6,494.3M（25名） vs GOD 9,233.0M（30名）＝約1.42倍差。GODは中堅の Nickyᶠᵘᶰ (573.7M) や ~Deadpool~ (442.9M) ら厚い兵量タンクが複数いるため、正面の多点消耗戦を避け、Top4の圧倒的火力差で敵兵を効率よく削る戦術が必須です。
⑤ 兵余裕 DTV — 出撃スタミナ余裕度 0 〜 100 点（目安60+）
一言イメージ：「聖剣1時間を通して前線に兵を出し続けられるスタミナ余裕」。
ただ兵が多いだけでなく、TG世代係数・推定兵量・総力内の兵比率 を組み合わせて「連戦に耐えられるか」を0〜100点で示します。
・兵量因子 a = clip(ln(1 + TroopPower_M / 20) / ln(31), 0, 1) [600Mで1.0]
・兵比率因子 s = clip((phi - 0.15) / 0.65, 0.02, 1.0)
・世代床係数 qf = max(1 - 0.04 × (8 - TG), 0.60)
DTV = 100 × qf × (a ^ 0.6) × (s ^ 0.4)
🎯 実戦での活かし方：SGR上位13名（班①②③）は全員 DTV 72〜100 と高水準。一方、TG6大兵（FAT_WARN）の3名（Ednan / kusabito / カピバラ） とD象限9名は主力TG8駐屯から分離し、別レーン＆終盤ハイスト要員として活かすのが最適解です。

📖 初心者向け：聖剣リーグ 重要ルール・用語ミニ辞典

📦 保有50%輜重ドロップ（エスクロー）聖剣では拠点を保持している間に貯まる同盟ポイントの 50%が拠点上に保管 されます。Phase 1から常に有効で、落城させると相手から引かれて周囲に箱が散らばり、どちらの同盟でも拾えます。
⏱️ 画面の「残り時間」見間違い注意戦場上部のタイマーは 60:00 → 00:00 のカウントダウン です。経過15分＝残り45:00、残り22:00以降は12分退場禁止（戻ってこられなくなるため）を徹底しましょう。
🏆 聖剣リーグは「得失点差」も重要勝敗だけでなく、シーズン昇格順位には 自軍ポイント − 相手ポイント（得失点差） も効きます。万一ビハインドでも、残り10分〜終了0秒まで箱・地下貯蔵庫を1つでも多く拾い切る価値があります。
