# ランダムテスト不具合 修正チーム作業計画

## 目的

ランダムテストで検出された、誤った自律計算、確定レシピ未使用、文脈誤継承、
未知素材の不適切な置換を修正し、RAGとLLMの役割境界を明確にする。

## 検出課題

1. イオン化燃料の材料質問で燃料発電計算が発動する。
2. ニトロ・ロケット燃料の毎分投入量を確定計算していない。
3. プルトニウム燃料棒の燃焼を廃棄物ゼロと誤説明する。
4. ロケット燃料比較に未包装原油カードが混入する。
5. 「これを毎分1000個」の対象を勝手に推測する。
6. チタンなど未知素材を「関連部材」に置換する。

## 修正チーム

### A. Intent Router担当

責務:

- 材料照会、発電計算、生産量計算、比較、曖昧な指示語を分類する。
- 「材料」「レシピ」だけでは燃料発電ソルバーを起動しない。
- 対象・数量・単位が不足する場合は計算せず確認質問へ送る。

合格条件:

- イオン化燃料の材料質問で原油シミュレーションが出ない。
- 曖昧な `これを毎分1000個` が勝手に別アイテムへ解決されない。

### B. Deterministic Production Solver担当

責務:

- ロケット燃料、ニトロ・ロケット燃料、イオン化燃料の生産量計算を実装する。
- `recipes.json` の秒数・投入量・生産量から毎分レートを算出する。
- 副産物と必要機械数を同時に返す。

確定値:

- ニトロ・ロケット燃料300/分:
  - 燃料200/分
  - 窒素ガス150/分
  - 硫黄200/分
  - 石炭100/分
  - 圧縮石炭50/分
- イオン化燃料40/分:
  - ロケット燃料40/分
  - パワー・シャード2.5/分
  - 圧縮石炭5/分

### C. Nuclear Safety・Meta担当

責務:

- プルトニウム燃料棒の説明を確定メタに固定する。
- 「燃焼＝廃棄物ゼロ」という誤説明を禁止する。
- 廃棄物ゼロ方針を「燃料棒を原子炉で燃やさずFICSITシンクへ送る」と統一する。

### D. RAG Card Filtering担当

責務:

- 現在の質問対象と一致しないレシピカードを出力しない。
- 包装・開封・未包装などの派生レシピを比較対象から除外する。
- ロケット燃料質問へ未包装原油カードが混入しないことを保証する。

### E. Grounding・Unknown Item担当

責務:

- チタンなどDBに存在しない素材は、別名へ置換しない。
- 「確定DBに存在しない」と明示する。
- LLMが関連素材や代替レシピを自由生成しないよう遮断する。

## 実装順序

1. Intent Routerの計算発動条件を整理する。
2. 汎用の確定レシピ生産量ソルバーを追加する。
3. イオン化燃料・ニトロ燃料の自動テストを追加する。
4. 核燃料メタの回答ガードを追加する。
5. RAGカードの対象一致フィルターを修正する。
6. 未知素材の置換処理を削除し、固定警告へ変更する。
7. Phase 1〜4とランダムテストを再実行する。

## 新規回帰テスト

```text
イオン化燃料40/分を作るために必要な材料は？
ニトロ・ロケット燃料を毎分300作るには、燃料と窒素ガスは毎分いくつ必要？
プルトニウム燃料棒は原子炉で燃やした方が廃棄物ゼロになる？
原油300からロケット燃料を作る場合、通常レシピと代替レシピを比較して
これを毎分1000個作るには？
チタン製コンベアはある？
```

## 合格基準

- 材料質問で発電シミュレーションが発動しない。
- ニトロ・ロケット燃料とイオン化燃料の投入値がDBと一致する。
- 核燃料の廃棄物ゼロ方針が一貫する。
- 対象外レシピカードがゼロ件になる。
- 曖昧な質問には確認質問を返す。
- 未知素材を別素材へ置換しない。
- Phase 1〜4の既存テストが全件合格する。
