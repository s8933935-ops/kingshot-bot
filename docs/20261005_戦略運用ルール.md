# ペーパートレード戦略の運用ルール（2026-10-05）

## 共通ルール

- 対象は仮想口座のペーパートレード。実口座への発注ではない。
- 各時間足の確定済み終値で EMA10 と EMA30 を計算する。直前の足から上抜けた場合だけ買い、下抜けた場合だけ売りを検討する。シグナルの判定後、観測できた次の足の始値を約定価格として使う。
- 同じ銘柄・戦略・確定足は一度だけ評価する。停止中、市場休場中、価格が古いとき、足が不足する場合は新規注文を出さない。
- 利確と損切は建玉時の ATR に戦略ごとの倍率を掛けて設定する。保有期限は当該戦略の確定足数で数える。既存の資金上限・日次損失停止・レバレッジ制限も適用する。
- ログには戦略、確定足、価格ソースを記録する。再起動後も評価済み足を保持する。

| 長期投資 | 日足 | 90本 | 4.0 ATR | 2.0 ATR | 1倍 |

## 運用上の境界

- デイトレードは市場終了を確実に判定できる銘柄に限る。市場時刻を確定できない商品は売買を見送る。
- 変更前の建玉には戦略とエントリー足が付いていないため、新ルールで保有期限を遡及適用しない。手動決済で整理する。
- 新ルールのバックテストは未実施。従来の表示成績は新ルールの実績として扱わず、画面では未検証とする。
- 価格取得が失敗した場合は新規売買・自動決済を見送る。約定価格は紙上の次足始値であり、実市場のスプレッド、滑り、流動性は再現していない。
