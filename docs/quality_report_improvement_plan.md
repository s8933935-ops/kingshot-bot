# 50ケース品質レポート 改善チーム作業計画

## 根拠

`data/quality_reports/quality_report_20260929_021521.json` の50ケース実行は40件合格、10件失敗。
失敗10件はすべて未知素材・建材の質問で、確定DB不在を固定回答せずLLMへ渡し、
「関連部材」「鋼鉄製コンベア」などへ置き換えて回答した。

## 改善チーム

### 1. Unknown Entity検出担当

- 未知素材・未知建材の質問をLLM実行前に分類する。
- チタン製コンベア、未知合金、架空素材Xなどの名称を推測補完しない。
- ユーザーの意図が存在確認・レシピ・材料照会なら固定のDB不在回答へ送る。

### 2. Grounding Guard担当

- 固定応答で「確定レシピDBに該当データがない」と明示する。
- 代替素材や近似アイテムを勝手に提案しない。
- 既存の未知燃料ガードと共通化する。

### 3. 出力フィルター担当

- 架空素材を「関連部材」へ置換する既存処理を廃止する。
- 回答中に既知の禁止架空名を検出した場合、固定の根拠不足回答へ差し替える。

### 4. 品質ランナー担当

- 50件の未知素材ケースを実出力経路で採点する。
- 期待語だけでなく、置換素材・代替建材・無関係レシピの混入も検出する。
- 失敗をケース別レポートに保存する。

## 作業順

1. Unknown Entity判定を追加する。
2. 未知エンティティをLLM呼び出し前に固定応答へ送る。
3. 「関連部材」置換を削除し、禁止語の漏出を固定応答へ差し替える。
4. 50ケースランナーを再実行する。
5. 失敗が残った場合は該当ケースを追加して再修正する。

## 合格基準

- 50ケースすべて合格。
- チタン、未知合金、架空素材Xを別素材名へ変換しない。
- 未知素材回答にレシピカードや無関係な発電計算を含めない。
- 通常の既知アイテム質問の回答を壊さない。
