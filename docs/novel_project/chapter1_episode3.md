# 携帯小説『アングラ・バカロード』
## 第1章：三人で作る嘘のない嘘
### 【第7話】消した場面の値段

---

#### ［１：タイムラインに光る「キラーカット」］

「Pさん！ ここ、マジで鳥肌立ちますよ！ ここ残せば、絶対に三十万再生はいきます！」

深夜一時。
上野のオレのアパートで、タカシが興奮してモニターのタイムラインを指差していた。

画面に映し出されていたのは、カオルのインタビューの後半、三十二分四十五秒の場面だった。
オレの「なぜ、この仕事を続けているんですか」という問いに対し、カオルがふと遠い目をし、煙草をくゆらせながら語り出した四分間の独白。

『……実はね、昔、銀座のクラブで働いてた頃に……ある上場企業の役員の男性と、本気で一緒になろうとしたことがあったの』

カオルは具体的な企業名、当時の男の役職、そしてその男が会社の粉飾決算に巻き込まれて失脚した際、どのように彼女を裏切り、借金を押し付けて逃げ去ったかを、生々しい固有名詞とともに語っていた。

『男なんて、金と立場がなくなったら、女を盾にして逃げる生き物よ。
だからアタシは……吉原に来たの。
最初からお金を介した関係の方が、よっぽど清潔で、裏切られないから』

カオルの声は静かだったが、その言葉には、胸をえぐるような冷たい怨嗟と哀しみが宿っていた。
誰が見ても、ネットの視聴者が最も食いつく「スキャンダラスで過激なキラーコンテンツ」。

「ここ、サムネで『元・銀座No.1が語る上場企業役員の裏切り』って打てば、まとめサイトが絶対に拾いますよ！」
タカシが息を荒げてマウスを握りしめた。
「Pさん、これですよ！ これがオレたちが探してた『本物』じゃないですか！」

オレの心臓も、激しく脈打っていた。
動画クリエイターとしての直感が、告げていた。
この場面を残せば、動画は跳ねる。
オレが今まで喉から手が出るほど欲しかった「数字」が、目の前に転がっているのだ。

だが――。
オレの胸ポケットには、あの四つ折りにした紙が入っていた。

〈一つ、動画をネットに公開する前に、必ずアタシが完成版をチェックし、削除を求めた箇所は一秒残らずカットすること〉

---

#### ［２：消去ボタンの重み］

翌日の昼下がり。
吉原『桃源郷』の控え室で、オレはノートPCを開き、カオルに編集済みの動画を見せた。

動画が終わると、カオルは無言で画面を閉じ、オレの顔をじっと見つめた。
その瞳は、冷たく引き締まっていた。

「……銀座の男の話。全部カットして」

「えっ……！？」
隣にいたタカシが、思わず声を上げた。
「カオルさん、あそこが一番いい場面ですよ！？ あれがあるから、カオルさんがどうして吉原で強く生きてるのかが視聴者に伝わるんじゃないですか！」

「伝わらなくていいわ」
カオルは冷淡に言い切った。

「あの話が出たら、当時の銀座のママや、昔の店の関係者がアタシの素性を特定するわ。
それに……相手の男には、今も家族がいるのよ。
アタシの昔の傷をネットのオモチャにして、無関係な人たちまで巻き込む気はないわ」

「でも……！」
タカシが食い下がろうとした。
「あそこを切ったら、ただの地味な対話動画になっちゃいますよ！ 数字が落ちるんですよ！？」

「タカシ」
オレはタカシの腕を掴み、制止した。

タカシの言っていることは正しい。
あの四分間を切れば、動画の爆発力は半分以下に落ちるだろう。
ネットのアルゴリズムは、刺激の強い過激な告白を好む。配慮された綺麗な言葉など、タイムラインの濁流の中ではあっという間に流されてしまう。

だが――。
オレはカオルの瞳の奥にある、微かな怯えを見逃さなかった。
強気で、何者にも屈しない女帝の顔の裏にある、「過去に傷つけられた一人の女性の恐怖」。

オレはノートPCの手元に指を置いた。
そして、編集ソフトのタイムライン上で、あの三十二分四十五秒から三十六分までのクリップを選択した。

Deleteキーを、静かに押した。

カチリ。
四分間の告白が、タイムラインから綺麗に消え去った。

「Pさん……！」
タカシが悔しそうに顔を歪めた。

オレはカオルに向き直り、深く頭を下げた。
「約束ですから。
カオルさんが守りたいものを脅かしてまで、オレたちは再生数が欲しいわけじゃありません」

カオルは驚いたように目を見張り、そして――ふっと柔らかく微笑んだ。
「……バカね、アンタ。数字、損したわよ」

「損していいんです。約束を守れる自分の方が、十万再生よりずっと価値がありますから」

#### ［３：届いた一通のダイレクトメッセージ］

三日後。
顔にAIモザイクをかけ、音声を不可逆変調し、慎重に編集されたカオルのインタビュー動画が、YouTubeに公開された。

タイトル――『【吉原の現場から】ナンバーワンが語る「お金で親密さを買う客」の哀しさと、夜の街の境界線』。

派手なサムネイルもなければ、過激な煽り文句もない。
再生数は、タカシが期待していたような爆発的な数字にはならなかった。
公開から二十四時間で、三万二千回。
前回のガールズバーの自爆動画の半分以下だった。

「……ほら、言ったじゃないですか」
アパートの床で、タカシが不貞腐れたように缶コーヒーを煽った。
「あそこ残しとけば、十万はいったのに。真面目にやりすぎなんすよ、Pさんは」

オレは何も言えず、画面の数字を見つめていた。
やっぱり、オレの判断は間違っていたのだろうか。
ネットの世界では、良心や配慮など、ただの弱さでしかないのだろうか。

その時だった。

ピロン。
オレのTwitter（X）のDMに、一通のメッセージが届いた。
通知のアカウント名は、歌舞伎町の有名キャバクラに在籍するキャストのものだった。

```
Pさん、初めまして。歌舞伎町で働いている○○です。
吉原のカオルさんの動画、拝見しました。

正直、見る前は「またよくある風俗嬢をバカにした晒し動画だろう」と思っていました。
でも、違いました。
カオルさんの言葉を、Pさんが茶化さず、変な下ネタに誘導もせず、
本当に一人の人間として真っ直ぐに聞いてくれているのが伝わってきて……
見ていて、涙が出ました。

私たち夜職の人間は、いつもネットのオモチャにされてばかりです。
でも、Pさんみたいな聞き方をしてくれる人なら……
私のお店のこと、私の仕事のことも、一度お話ししてみたいと思いました。
もしよろしければ、取材に来ていただけないでしょうか？
```

画面を見つめたまま、オレの指先が震えた。

「……タカシ」
オレはスマホをタカシに見せた。

タカシは画面を覗き込み、息を呑んだ。
「これ……歌舞伎町の超有名店の子じゃないですか……！」

「数字は……落ちたかもしれない」
オレは喉の奥を熱くしながら言った。
「でもな、タカシ。
オレたちが過激な暴露を切って、約束を守ったからこそ……
この街で本当に戦っている人たちからの、『信頼』が生まれたんだよ」

タカシはスマホを見つめたまま、何も言えなくなっていた。
その瞳に、数字の大小だけでは測れない「表現の重み」が、静かに刻み込まれていくのが分かった。

配慮は、損失ではない。
誰かの痛みを削ぎ落とした空白にこそ、次の本物の言葉が宿るのだ。
オレたちの番組は、小さく、だが決定的な信頼の錨を、夜の街の海底へと下ろしたのだった。
