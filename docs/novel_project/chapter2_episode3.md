# 携帯小説『アングラ・バカロード』
## 第2章：売れたぶんだけ、逃げられない
### 【第11話】五千人では足りない

---

#### ［１：膨らむ数字と、消える自由］

四月中旬。
制作会社『メディアルート』との提携から二ヶ月。
独自会員制サロン『アングラ・ラボ』の会員数は、佐々木たちの広告出稿とインフルエンサーの告知により、一気に【五千二百人】へと跳ね上がっていた。

月間売上高：約一千三十万円。
ついに大台の一千万円を超えたのだ。
六畳一間のアパートで、電気代七千八百四十円に怯えて泣いていた半年前のオレから見れば、天文学的なサクセスストーリーに見えるはずだった。

だが――上野の事務所の会議テーブルに置かれた収支内訳書は、まったく別の現実を冷酷に語っていた。

```
［ 4月度 月間収支内訳（会員5,200人） ］
・総売上高：                      10,296,000円
・メディアルート配分（60%）：     - 6,177,600円
・サーバー・CDN従量課金費：       - 1,200,000円
・スタジオレンタル・設備維持費：    - 850,000円
・出演者ギャランティ（12名分）：   - 1,200,000円
・タカシチーム撮影・編集委託費：    - 550,000円
━━━━━━━━━━━━━━━━━━━━━━━━━━━
P-PROJECT 手元純利益：               318,400円
```

売上高一千万円に対して、残る純利益は、わずか三十一万円。
規模が五倍に膨らんだのに、オレたちの手元に残る金は、会員八百人だった頃とほとんど変わっていなかった。

「……おかしいっすよ」
タカシが目の下に濃い隈を作りながら、エナジードリンクの空き缶を机に叩きつけた。
週に三本の納品スケジュールに追われ、タカシは連日スタジオと編集室に泊まり込んでいた。

「会員が五千人に増えたのに、作業量は十倍になって、利益は数十万って……。
サーバー代も、出演料も、全部オレたちの取り分から引かれてるじゃないですか。
メディアルートは何も作ってないのに、売上の六割を無条件で持っていってる。
こんなの……ただのデジタル小作人じゃないですか！」

タカシの悲痛な叫びが、狭い事務所に響いた。

「タカシ君の言う通りよ」
カオルが冷たい目をして、煙草の煙を吐き出した。
「最初からそういう契約よ。あいつらは、制作準備費の一千五百万円を回収するまで、絶対に手綱を緩めない。
今やめれば、第15条の違約金で一千五百万円の一括返済を求められて、アタシたちは即座に自己破産よ」

---

#### ［２：三人の亀裂］

「じゃあ、どうするんですか！」
タカシが食ってかかった。

「これ以上、動画の本数を増やしたらオレ、本当に過労で倒れますよ！
もう大きなフェス企画なんてやめて、昔みたいにPさんとカオルさんと三人で、
夜の街の小さなインタビューをじっくり撮るスタイルに戻しましょうよ！
会員が二千人に減ったって、支出を削れば三人で食っていけるじゃないですか！」

タカシの提案は、痛いほど誠実だった。
原点に戻ること。
他人の資本に依存せず、自分たちの手の届く範囲で、人を消耗させない番組を作ること。

だが――カオルは首を横に振った。

「甘いわよ、タカシ。
途中で規模を縮小したら、メディアルートは『契約不履行』で素材の権利を全部差し押さえにくるわ。
あいつらから逃げる方法は一つしかない。
もっとデカい企画を打って、会員を一万人、二万人にして、
あいつらに払う契約金の残額を一日でも早く完済して、契約を買い取って独立することよ」

カオルの言葉もまた、現実の商売を知る者としての、冷徹な生存戦略だった。
負債を清算するためには、より大きな利益を叩き出すしかない。

「縮小して守る」タカシ。
「拡大して脱出する」カオル。

二人の視線が、中央に座るオレ――田中智裕へと注がれた。

「Pさん。Pさんはどう思ってるんですか？」
「P。代表はアンタよ。決めなさい」

---

#### ［３：鏡の中の傲慢］

オレは手帳を見つめたまま、唾を飲み込んだ。

オレの頭の中では、電卓が激しく弾かれていた。
だが――オレの心臓を本当に動かしていたのは、金勘定の数字ではなかった。

（……戻りたくない）

心の奥底から、黒い本音が湧き上がってきた。

鶯谷の路地裏で、誰にも見向きもされず、18回しか再生されなかったあの惨めな日々。
会社のオフィスで「おじさん」と呼ばれ、紙詰まりを直していた透明人間の自分。
あの場所には……二度と戻りたくない。

今、オレは「P」として、ネットのアンダーグラウンド界隈で注目されている。
六本木のプロデューサーから頭を下げられ、大物インフルエンサーからコラボを求められ、
五千人もの人間が、オレの企画した番組を見るために金を払っている。

「……タカシ」
オレは顔を上げ、タカシの目を見つめた。
できる限り、プロデューサーらしい落ち着いた声を装いながら。

「カオルさんの言う通りだ。
中途半端なところで足を止めたら、違約金で全員が潰れる。
次の大型フェス企画……『六本木ラウンジ vs 吉原ソープ　夜の頂点決定戦』を打つぞ。
あのアクリル水槽をフルに使って、日本中の注目を集めるんだ」

タカシの顔から、表情がサーッと引いていった。
「……Pさん。本気ですか？
あんな過激な煽り合いの企画、出演する女の子たちの生活がめちゃくちゃになりますよ……！
最初の約束はどうしたんすか！？ 『他人の尊厳を守る』って言ってたじゃないですか！」

「守るよ！ モザイクも安全管理も、オレが完璧にやる！」
オレは声を荒らげた。
「オレだって必死なんだよ！
オレが熱湯に落ちて、一番無様なピエロをやれば、誰も傷つかずに済むんだよ！！」

オレの叫び声に、事務所が静まり返った。

タカシは唇を噛み締め、何も言わずに部屋を出て行った。
バタン、とドアが閉まる音が、重く響いた。

カオルだけが、煙草をくわえたまま、冷ややかな瞳でオレを見つめていた。
その瞳は、すべてを見透かしていた。

「……P。アンタ、タカシのためでも、アタシのためでもないわね」

カオルは静かに立ち上がり、オレの耳元で囁いた。

「アンタが本当に怖がってるのは、違約金じゃない。
誰にも見られなくなって……ただの『田中智裕』に戻ることよ」

胸の奥を、冷たい針で深く刺されたような痛みが走った。
反論の言葉は、一言も出てこなかった。

成功という麻薬が、オレの倫理の境界線を少しずつ、確実に溶かしていた。
「自分が耐えているのだから、他人も少しくらい耐えるべきだ」。
その傲慢の罠に自ら足を踏み入れていることに、オレはまだ気づいていなかった。
