# 携帯小説『アングラ・バカロード』
## 第4章：熱湯の審判：ピエロの戴冠（完結編）
### 【第6話】ピエロの戴冠、そして円環の彼方へ（大団円）

---

#### ［１：二百万人の前での重大発表］

チャット欄の嵐のようなコメントの滝を見つめながら、オレはマイクを握りしめ、苦笑いを浮かべていた。

「……みなさん、本当に勝手なことを言いますね。
オレは今夜、人生の破滅の淵から這い上がってきたばかりなんですよ？
なのに……『勝ったから熱湯に落ちろ』ですか？」

――『当たり前だろ！ それがPだ！』
――『落ちてこそ完成するんだよ！』
――『熱湯に入って完全勝利の儀式をしろ！』

二百万人の視聴者が、歓喜の笑い声とともにオレを煽り立てていた。
オレは飛び込み台へと歩み寄ろうとした。
その時だった。

カツ、カツ、カツ……。

ルブタンのハイヒールの乾いた音が響き、黒のタイトドレスを着たカオルが、オレの手から無造作にマイクを奪い取った。

「……ちょっと、P。アンタ、大事なことを忘れてるんじゃない？」

「えっ……？ カオルさん？ 大事なことって……」

カオルはオレを一瞥もせず、真っ直ぐにメインカメラのレンズを見据えた。
その瞳には、五年間吉原の頂点に君臨し、数多の修羅場を越えてきた女帝の、すべてを飲み込むような妖艶で、だが揺るぎない覚悟の光が宿っていた。

スタジオの照明が、カオルの美しい横顔を照らし出す。
二百万人の視聴者が、静まり返った。

カオルはマイクを口元に寄せ、凛とした、通る声で告げた。

「――全国の視聴者の皆様。そして、吉原、歌舞伎町、六本木をはじめとする、夜の街のすべての皆様へ」

一拍の、神聖な静寂。

「私、吉原『桃源郷』の源氏名カオル――本名・綾瀬薫は。
本日をもちまして、夜職の現役を完全に引退いたします。
そして――ここにいる、世界一情けなくて、世界一無様で、世界一諦めの悪いバカ……『P』こと山田大介と、婚約いたしました」

――――――――――――ッッッ！！！！

コンマ一秒の完全な空白ののち、YouTubeと独自サロンのサーバーが、文字通り音を立てて悲鳴を上げた。

ドッギャアアアアアアンッッッ！！！！

チャット欄が、もはや文字ではなく真っ白な光の津波となって吹き飛んだ。

――『はああああああああああああああっ！？！？』
――『えええええええええええええええええ！？！？』
――『吉原の女帝が！？ カオル様が！？』
――『あのハゲのおっさんと結婚！？！？』
――『嘘だろおい！！ 全人類の夢と希望が今ここに爆誕したぞ！！』
――『おめでとうぅぅぅぅぅぅぅぅぅっ！！』

「え……えええええええええっ！？」
飛び込み台の前で、オレは顎が外れそうになって絶叫した。
「カ、カオルさん！？ な、何を言ってるんですか！？ オレ、そんな話、一言も聞いてませんけど！？」

カオルはフッと口角を上げ、オレの胸元に人差し指を突き立てた。

「何言ってるのよ。
アンタの会社の財務も、法務も、口座も……そして人生のすべてを、アタシが管理するって言ったでしょ。
アンタみたいなバカ、アタシが一生手綱を握ってケツを蹴飛ばしてあげなきゃ、また悪い奴に騙されて東京湾に沈むに決まってるじゃない。
……逃げられると思ってたの？」

カオルの瞳の奥に、ほんの微かに潤んだ、世界で一番温かい光が揺らめいていた。

彼女は、金や見栄で女を買う何百人もの男たちを見てきた。
だが、全財産を失っても、泥水をすすっても、最後まで仲間とキャストを守り抜き、笑顔でピエロとして生きる道を選んだこの男だけが――
彼女がその人生のすべてを賭けるに値する、世界でたった一人の「本物の男」だったのだ。

オレの視界が、涙で滲んだ。
三十九年間、誰にも名前を呼ばれず、透明人間として生きてきた男の前に現れた、最高の理解者。

「……カオルさん。オレ、一生アンタのピエロとして生きますよ」

「当たり前でしょ、ハゲ」

#### ［２：伝説の熱湯ウエディング・ダイブ］

チャット欄は、すでに祝福と狂乱のるつぼと化していた。

――『婚約したなら熱湯に落ちろ！！』
――『二人で落ちろ！！ 熱湯ウエディングだ！！』
――『一生忘れられない結婚式にしてくれ！！』

「タカシ！ カメラ回せ！」
オレは叫びながら、タキシードのジャケットを脱ぎ捨てた。
「全国の二百万人の皆様！ オレたちP-PROJECTは……幸せの絶頂だからこそ、落ちます！！」

オレは二・五メートルの飛び込み台の先端へ駆け上がり、両手を広げた。
四十四・五度の巨大アクリル熱湯要塞が、湯気を上げてオレを待っている。

「カオルさん！ 合図を！！」

下で見上げていたカオルが、破顔一笑した。
吉原の女帝が、世界で一番無邪気な少女のような笑顔を浮かべて叫んだ。

「――落ちなさい、アタシの可愛い旦那様ぁぁぁぁッ！！」

ドッッッッッッボォォォォォォンッ！！！！

水槽の底まで突き抜ける、凄まじい水柱。
四トンの熱湯の海に、オレの身体が真っ逆さまに沈み込んだ。

「あづいぃぃぃぃぃぃぃぃぃぃぃッッッ！！
幸せだけど、あづいいいいいいいいッッ！！」

水面に顔を出したオレの頭上から、白いシルクのストールを羽織ったカオルが、ヒールを脱ぎ捨てて飛び込んできた。

ザバァァァァァァンッ！！

「きゃははははっ！ 本当に熱いじゃないの、これ！！」
ドレスをびしょ濡れにしたカオルが、水中でオレの肩にしがみついて笑い転げた。

「オレも行きますよぉぉぉぉっ！！」
タカシが防水カメラを抱えたまま、頭から水槽へダイブした。

ドッボオオオンッ！！

アクリルパネル越しに、水中で抱き合い、バタ足をしながら、真っ赤な顔で笑い合う三人の姿が丸見えになっていた。
二百万人が見守るモニターの向こうで、チャット欄には無数の「おめでとう」の弾幕が、星空のように輝いていた。

スタジオの外、公用車の後部座席に乗り込もうとしていた東京国税局の鬼頭統括官が、タブレットの画面をチラリと見下ろし――。
ふっと、誰にも気づかれないように口元を緩め、夜の闇の中へと消えていった。

#### ［３：エピローグ――真鍮の南京錠］

――あれから、数年の月日が流れた。

東京・港区の一等地にそびえ立つ、ガラス張りの自社ビル。
『P-PROJECT HOLDINGS』の最上階、広大な社長室。

あの人が過労で倒れて病院に担ぎ込まれた夜、オレ――タカシは、スペアキーを探すために、執務デスクの最下段の引き出しに掛けられていた真鍮の南京錠を、ドライバーでこじ開けた。

中から転がり出てきたのは、金目のものなどではなかった。

埃をかぶった黒い耐衝撃外付けハードディスク（2TB）。
手垢で茶色く変色し、糊で何重にも継ぎ接ぎされたボロボロの大学ノート。
そして、スーパーのレジ袋に詰め込まれた、百枚を超える領収書の束。

『鶯谷　リラクゼーション○○　14,000円』
『西川口　メンズエステ○○　18,000円』
『湯島　ガールズバー○○　48,400円』
『吉原　桃源郷　128,000円』

インクの薄れた感熱紙のレシートの山の中に、一枚のカラー写真が挟まれていた。

千葉の倉庫スタジオ。
四十四・五度の巨大アクリル熱湯水槽の中で、びしょ濡れになり、湯気を立ち上らせながら、真っ赤な顔でアホ面を晒して笑っている中年男・Pと――
その隣で、泥臭い笑顔を浮かべてPの頭を小突いている、白いドレス姿のカオル。

大学ノートの最終ページ。
ボールペンのペン先が紙を突き破り、裏の三枚先まで窪みを残すほどの凄まじい筆圧で刻まれた、あの言葉の横に――
流麗な細いペンの文字で、こう書き足されていた。

――【死んでも諦めるな。オレは絶対に、この時代に爪痕を残す】
――【爪痕どころか、日本中に大穴を開けたわね。一生付き合ってあげるわ、バカP】

窓の外には、きらびやかな東京のネオンが広がっていた。

誰からも愛されなかった男が、泥水をすすり、熱湯に落ちて、日本中を笑わせながら掴み取った、本物の愛と栄光の軌跡。

アングラ・バカロード。
その狂気と執念の旅路は、いま、伝説となって永遠に語り継がれる。
