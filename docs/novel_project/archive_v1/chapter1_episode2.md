# 携帯小説『アングラ・バカロード』
## 第1章：泥水と金勘定：アングラ同盟の産声
### 【第2話】最初のバズ『ガチの金欠の恐怖』（超濃密・文庫完全版）

#### ［１：カウンターの冷気と、プロの商人］

午後七時五分。
湯島の雑居ビル地下、ガールズバー『ル・シエル』。

重い防音ドアを開けた瞬間、冷房の冷気とともに、甘ったるいバニラの香水と安っぽい消臭スプレーが混ざり合った独特の匂いが、オレの鼻腔を突いた。

店内は薄暗く、青と紫の間接照明がカウンターの黒い人造大理石を艶めかしく照らしている。
客はオレ一人。BGMには、低音の効いた洋楽ポップスが気だるげに流れていた。
厨房の奥から、先ほどの店長が無愛想に顔を出し、アゴでカウンターの最奥――レジの横、換気扇の真下の席を指した。

「……そこ。端っこな。カメラは客席や厨房には絶対向けるなよ」

「あ、はい……失礼します」

オレは小さく頭を下げ、革張りのハイチェアに腰掛けた。
ダウンジャケットを脱ぐと、脇の下に嫌な汗がびっしょりと滲んでいた。
胸ポケットにクリップで留めた超小型のアクションカメラ。レンズの向きを微調整し、カウンターの向かい側だけを正確に捉える画角に固定する。

カツ、カツ、と高めのヒールの音が近づいてきた。
カウンターの向かい側に立ったのは、黒いオフショルダーのタイトドレスを着た、二十歳そこそこの若い女だった。
巻き髪を肩に流し、メイクは完璧。だが、その瞳の奥には、オレを一目見た瞬間に「品定め」を完了させた、夜の商売人特有の冷淡な光が宿っていた。

「いらっしゃいませー。初めまして、ナナです」

口角だけをキュッと上げた、営業用の笑顔。
声のトーンは明るいが、目元はまったく笑っていない。
彼女にとって、七時という早い時間帯に一人でふらりと入ってきた、ヨレヨレのスーツを着た中年男など、「暇つぶしの安客」以外の何物でもないのだ。

「あ、ど、どうも……。Pと申します……」

オレは引き攣った愛想笑いを浮かべながら、メニュー表を開いた。
基本料金は、四十割ワンセット三千五百円。飲み放題。
（よし、これなら……税金やサービス料を入れても、五千円前後で収まるはずだ）
ポケットの中にある、全財産の一万二千円を頭の中で反芻し、オレは微かに安堵の息を漏らした。

だが――夜の街のシステムは、そんなに甘く作られてはいなかった。

#### ［２：地獄の沈黙とおねだりの罠］

「Pさんって、お仕事帰りですかー？」

ナナがグラスにウーロン茶を注ぎ、オレの前にコトンと置いた。
爪には大粒のラインストーンが光り、指先が触れるか触れないかの絶妙な距離感でコースターを滑らせてくる。

「え、ええ……まあ、事務というか、パソコン関係の……」

「へぇー、すごーい！ パソコン得意な人ってかっこいいですよねー」

完全に心がこもっていない、棒読みの相槌。
会話のキャッチボールは、そこですぐに途切れた。
店内には気まずい沈黙が流れ、氷がカランと溶ける音だけがやけに大きく響く。

オレは焦った。
胸の小型カメラは、今まさにこの瞬間も録画を続けているのだ。
（何か喋らなきゃ……！ 面白いことを言わなきゃ、動画にならない……！）

「あ、あの！ ナナさんは、普段お休みの日は何されてるんですか！？」

絵に描いたような、素人の痛い質問。
ナナは小さく息を呑むようにして、ふっと口元を歪めた。
「休みですかー？ んー、寝てますね。基本ずっと寝てるか、ネトフリ見てるか」

「そ、そうなんですね！ ネトフリ！ オレも……あ、ドキュメンタリーとか、刑務所の潜入記とかよく見ます！」

「……へぇ。刑務所。渋いですね」

ナナの視線が、すっとオレから外れ、壁掛け時計へと移った。
あからさまな退屈のサイン。
男としての魅力もなければ、軽妙なトーク力もない。ただ汗をかいてオドオドしているだけの四十前のオッサン。
彼女にとって、この時間は「苦痛な拘束時間」でしかないのだ。

すると、ナナはおもむろに首を傾げ、上目遣いでオレの顔を覗き込んできた。
その表情は、先ほどまでの退屈顔から一変し、獲物を狩る雌豹のような計算高い甘さに満ちていた。

「ねえ、Pさん」

「は、はい！？」

「ナナも、何か飲んでもいいですかー？ 喉乾いちゃって」

来た。
夜の街の最大のトラップ、「キャストドリンクのおねだり」だ。

オレの頭の中で、電卓が激しく弾かれた。
（女の子のドリンクは……一杯いくらだ？ 千円か？ 千五百円か？ でも、ここで断ったら完全に空気が死ぬ。撮影も台無しになる）

「あ、どうぞどうぞ！ 好きなの飲んでください！」

見栄を張って、オレは力強く頷いた。
その瞬間、ナナの目がパッと輝いた。

「やったー！ ありがとうございます！ 店長ー、ショットでテキーラもらっていいですかー？」

ナナは慣れた手つきで、カウンターの奥に声をかけた。
店長が無言で差し出してきたのは、ショットグラスに入った透明な液体。
「じゃあ、Pさん、かんぱーい！」

クイッと一気に煽るナナ。
「んー、美味しい！ Pさん、優しいー！」

そこからの展開は、まさに蟻地獄だった。
一度ドリンクを奢ったことで、ナナの「営業エンジン」が完全に点火したのだ。
だがそれは、オレとの会話を楽しむためではない。「いかに短時間でオレからドリンクを巻き上げるか」という、純粋なノルマ達成のゲームだった。

「Pさん、もう一杯いいですか？ 喉渇いちゃったー」
「あ、じゃあ……はい」
「店長ー！ もう一杯！」
「ナナの友達のアイリも呼んでいいですかー？ 一緒に乾杯しましょー！」
「えっ、あ、アイリさん……？」

気づけば、カウンターの向かいにはもう一人、派手な金髪の女の子が座っていた。
「初めましてー！ Pさんドリンクごちそうさまでーす！」
「あ、はい……」

断れない。
「ダメです」の一言が、喉の奥に張り付いて出てこない。
カメラを回している手前、みっともなくケチなところを見せたくないという、救いようのない男の見栄。
乾杯の音が響くたびに、オレの脳裏には「千円札に羽が生えて飛んでいく幻覚」がチラついていた。

「Pさーん、お時間なんですけど、延長どうされますかー？」

背後から、店長がぬっと現れて囁いた。
時間はあっという間に四十時間が過ぎていた。
ここで帰れば、まだ傷は浅い。だが、ナナがオレの腕にそっと手を重ね、潤んだ瞳で見つめてきたのだ。

「えー、Pさんもう帰っちゃうの？ ナナ、Pさんともっとお話ししたいなー」

もちろん、完全な嘘八百の営業トークだ。
だが、生まれてこの方、若い女にそんな台詞を言われたことのないオレの脳は、完全にショートした。

「……じゃ、じゃあ、ワンセットだけ、延長で……」

口から出た瞬間、オレは自分の愚かさに、心の中で絶叫していた。

---

#### ［３：伝票の数字と、バリバリ財布の悲劇］

延長の四十割も、瞬く間に過ぎ去った。
二人の女の子は、テンション高くテキーラを何杯も飲み干し、オレが話す痛々しい自虐ネタに適当に相槌を打ちながら、スマホの画面をチラチラと気にしていた。

午後八時半。
「お会計になりまーす」

店長が、黒いレザー調の伝票バインダーを、カウンターの上にコトンと置いた。

ナナとアイリは、伝票が置かれた瞬間、さっきまでの甘ったるい笑顔をスンと消し去り、
「ごちそうさまでしたー」「ありがとうございましたー」
と事務的に頭を下げると、奥のスタッフルームへと足早に消えていった。
用済みの客に対する、鮮やかすぎるほどの潮引き。

カウンターに残されたのは、オレと、一枚の伝票だけだった。

震える指先で、オレはバインダーを開いた。
そこに印字されていた数字を見た瞬間、心臓がドクンと嫌な音を立てて跳ね上がった。

```
［ 御会計票 ］
セット料金（40分×2）：  7,000円
キャストドリンク（×12）： 18,000円
ショット特別料金：        6,000円
指名料（場内×2）：       4,000円
サービス料（20%）：       7,000円
消費税（10%）：           4,200円
━━━━━━━━━━━━━━━━━━━━
合　計：                 48,400円
```

「よ、よんまんはっせん……！？」

声が裏返りそうになった。
五千円で済むはずだった。高くても一万円前後のつもりだった。
それが、四十割の延長と、女の子二人が浴びるように飲んだショットと、知らぬ間につけられていた場内指名料、そして深夜歓楽街特有の凶悪なサービス料とTAXの二重掛けによって、五万円近い巨額の請求へと膨れ上がっていたのだ。

冷や汗が、背筋を滝のように流れ落ちる。
オレの全財産は、一万二千円しかない。

（ど、どうする……！？ 警察を呼ばれるか！？ それとも裏の事務所に連れて行かれてタコ殴りにされるか！？）

店長が、腕組みをしたまま無言でオレの顔をじっと見つめている。
その目は、「払えねえなら分かってんだろうな」という無言の威圧感を放っていた。

オレは震える手で、スラックスのポケットから財布を取り出した。
高校生の修学旅行の時に買った、薄汚れたナイロン製のアウトドア財布。

静まり返った店内に、情けない破裂音が響いた。

バリバリバリッ――！

マジックテープを剥がす乾いた音が、静寂を切り裂いた。
カウンターの奥で、グラスを洗っていた店長の眉がピクリと跳ねる。

中から取り出したのは、なけなしの野口英世が一枚と、数枚の小銭。
そして――限度額が十万円しかない、年会費無料の格安クレジットカード。

「あ、あの……カ、カードで……払えますでしょうか……」

声が震えて、蚊の鳴くような音しか出なかった。
店長はオレのマジックテープ財布と、ボロボロのクレジットカードを一瞥し、深いため息を吐いた。

「……カードは手数料一割増しになりますけど、いいですか」

「は、はい……！ お願いします……！」

端末にカードが差し込まれる。
通信中のインジケーターが、ピピッ、ピピッ、と点滅する。
このカードのショッピング枠は、先月のサーバー代とプロテインの購入で、すでに九万近く使っていたはずだ。
もし、枠が足りずにエラーが出たら――その場でゲームオーバーだ。

神様、仏様、どうか通ってくれ……！
オレはカウンターの下で、脂汗にまみれた手を固く握りしめ、祈った。

ピピピッ。
『承認されました』

ガシャン、とレシートが吐き出された。
「……ありがとうございました」

店長の冷たい声とともに、サインを済ませたオレは、逃げるように店を飛び出した。

#### ［４：送電停止の恐怖と、本気の涙目］

地下の階段を駆け上がり、冷たい夜風が吹きすさぶ湯島の路地裏に飛び出した瞬間、オレの膝はガクガクと崩れ落ちた。

「助かった……死ぬかと思った……」

壁に手をつき、荒い息を吐く。
だが、安堵の時間は一秒も続かなかった。
ポケットの中で、スマホがブブッと短く震えたのだ。

画面を開くと、クレジットカード会社からの利用通知メール。
『ご利用金額：53,240円（手数料込）』
『ご利用可能残高：0円』

枠を、綺麗に使い切っていた。
そして――そのメールの直後に、もう一通の通知が画面にポップアップした。
送信元は、東京電力。

『【重要】電気料金未払いによる送電停止予告のご案内』
『平素よりご利用いただきありがとうございます。未納分の電気料金（7,840円）につきまして、期日までのお支払いが確認できておりません。明日午後五時までにお支払いが確認できない場合、送電を停止させていただきます』

「……え？」

スマホの画面を見つめたまま、オレの思考は完全に停止した。
手元にある現金は、財布に残った小銭の数百円だけ。
銀行口座の残高は、今朝の時点で千八百円。
クレジットカードは限度額ゼロ。
給料日は――まだ二週間先だ。

明日の夕方、電気が止まる。
電気が止まれば、自作PCは起動しない。
冷蔵庫の食料は腐り、スマホの充電もできず、真冬の寒空の下、暖房もつかない部屋で凍えることになる。

「嘘だろ……？ なんで……なんでこんなことに……」

情けなさと、自己嫌悪と、底知れぬ恐怖が、一気に喉元までせり上がってきた。
いい年こいた四十前の男が。
夜の街の若い女の子にいい顔をして、調子に乗って見栄を張り、テキーラを何杯も奢らされ、マジックテープの財布をバリバリ言わせて五万以上の金を巻き上げられ、明日電気が止まる。

惨めだった。
死ぬほど惨めだった。
何がアングラプロデューサーだ。何が時代に爪痕を残すだ。
オレはただの、夜の街のカモにされた、救いようのない哀れな中年ピエロじゃないか。

ポロポロと、涙がこぼれ落ちた。
誰に見せるためでもない、演技でも演出でもない。
「ガチで金がなくて、明日電気が止まる」という、生存の危機に直面した男の、本気の涙だった。

オレは路地裏の自販機の横にしゃがみ込み、鼻水をすすりながら、胸元の小型カメラを取り外した。
カメラの赤い録画ランプは、まだ点滅していた。

オレがカウンターでオドオドしていた姿も。
女の子にいいようにカモにされていた姿も。
伝票を見て白目を剥いた姿も。
マジックテープ財布を落としそうになった姿も。
そして今、路地裏で電気代が払えなくて泣いているオレの無様な顔も――。
そのすべてが、完全に記録されていた。

オレは涙で濡れた袖口で目をこすり、レンズに向かって、震える声で呟いた。

「……みなさん。これが……これが、夜の街です……。オレは今夜、五万円を失いました……。そして……明日、電気が止まります……」

自嘲の笑みが、涙の中に滲んだ。
痛みをエンタメに変える。
それしか、オレに残された道はなかった。

#### ［５：二十万再生の爆発］

翌朝。
電気が止まるリミットまで、あと八時間。
オレは目の下に真っ黒なクマを作りながら、猛烈な勢いで動画の編集を完結させた。

店名と女の子のプライバシーは、自作AIの『YOLOv8マスク』と音声不可逆変調によって、完璧に保護した。
顔には漆黒のスタイリッシュな幾何学マスク。声は誰のものかもわからないロボット風の変調。
だが――カウンターの冷気、ナナの計算高い視線、伝票が置かれた瞬間の絶望、マジックテープのバリバリ音、そして路地裏で本気で泣きじゃくるオレの姿は、一切のカットを挟まず、ノー編集の長回しで叩き込んだ。

タイトルは――。
『【自腹破産】湯島のガールズバーに潜入したら40分で5万円溶けて明日電気が止まることになりました【ガチ号泣】』

サムネイルには、五万三千円の伝票のアップと、マジックテープ財布、そして路地裏で鼻水を垂らして呆然としているオレの顔。

ポチッ、とアップロードボタンを押した。
それが、午前十一時のことだった。

そこからの爆発は、オレの貧相な想像力を遥かに超越していた。

アップロードからわずか三十分後。
再生回数は一万回を突破。
一時間後、五万回。
三時間後、十万回。
そして夕方、電気が本当にプツンと音を立てて消え、部屋が真っ暗になった午後五時過ぎ――スマホの画面の中で、動画の再生回数は【二十三万回】を記録していた。

コメント欄は、爆笑と共感と戦慄の嵐だった。

――『おっさんマジで泣いてて草生える』
――『ヤラセかと思ったら伝票の明細がガチすぎて笑えない』
――『マジックテープの「バリバリッ」って音で腹筋崩壊したww』
――『電停予告のSMS見せてくるところで本物の狂気を感じた』
――『これぞ求めてたアングラレポ。ヤラセだらけの有名YouTuber共は見習え』
――『おっさん、電気代カンパしてやるから口座晒せ！』

登録者数は、一千六百人から一気に一万二千人へ。
スーパーチャット（投げ銭）の機能はまだ解放されていなかったが、オレのTwitter（X）のDMには、数百件のメッセージが殺到していた。

暗闇に包まれた六畳一間のアパート。
エアコンも止まり、吐く息が白くなる極寒の部屋の中で、オレは青白く光るスマホを握りしめ、震えていた。

寒い。腹が減った。電気もない。
だが――オレの心臓は、これまでの三十九年間の人生で、最も熱く、激しく脈打っていた。

「ウケた……。オレの情けなさが……この無様な生き様が、世の中に刺さったんだ……！」

ピエロは、笑われてこそ輝く。
自分の恥と絶望を差し出せば、時代は金を払って拍手を送ってくれる。
その残酷で甘美な真理を、オレは真っ暗な部屋の中で、骨の髄まで噛み締めていた。

だが、この熱狂の匂いを嗅ぎつけたのは、純粋な視聴者だけではなかった。
ネットの深淵に漂う、さらに危険で、飢えた獣たちが、オレの元へと引き寄せられ始めていたのだ。
