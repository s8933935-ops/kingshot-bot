# 携帯小説『アングラ・バカロード』
## 第4章：熱湯の審判：ピエロの戴冠（完結編）
### 【第5話】前代未聞の生配信『熱湯公開査察』

---

#### ［１：赤く光るRECランプ、二百万人の視線］

ピピッ。
スタジオの天井から吊り下げられた八台の4Kシネマカメラの赤いインジケーターが、一斉に点滅を開始した。

午後八時整。
千葉県野田市、あの特注アクリル熱湯水槽が鎮座する三百坪の廃倉庫スタジオ。
YouTubeのライブ配信枠、そして独自会員制サロン『VIP CLUB』の特設中継サーバーが、全世界に向けて解き放たれた。

配信タイトル――。
『【ノーカット生中継】国税査察の現場と、週刊誌捏造報道のすべての証拠を公開します【P-PROJECT最終決戦】』

配信開始から、わずか三分。
同時接続者数を示す赤いカウンターが、物理法則を無視したような垂直跳びで狂い咲いた。

『同接：150,000人』
『同接：580,000人』
『同接：1,200,000人』
『同接：2,050,000人』

二百万人。
日本のYouTubeライブ配信史上、前人未到の天文学的な数字。
地上波のテレビ特番を遥かに凌駕する、日本中のスマホとパソコンの画面が、この千葉の倉庫スタジオの一点へと集中していた。

チャット欄のスクロールは、文字が肉眼で認識できないほどの光の奔流となって吹き荒れていた。

「……集まったわね、日本中の野次馬共が」
スタジオの袖で、カオルが黒のタイトドレスを着こなし、冷徹に微笑んだ。

スタジオの中央。
透明度八十ミリを誇る巨大アクリル水槽の水面からは、ボイラーによって加熱された白い湯気がゆらゆらと立ち上っていた。
デジタル水温計の赤い文字は、いつも通りの『44.5℃』を示している。

そして――水槽の向かい側、強化ガラスのパーテーションで区切られた特設ブースには、スーツ姿の男たちが整然と陣取っていた。
東京国税局査察部・鬼頭統括官、そして五名の査察官たち。
その対面には、顧問弁護士の神崎、公認会計士・税理士の水野が、山のような総勘定元帳と電子帳簿のハードディスクを並べて着席していた。

#### ［２：冷徹なる国家権力と、電磁的真実］

鬼頭は、生配信のカメラに目線を送ることは一切しなかった。
国家公務員としての守秘義務、そして百戦錬磨の査察官としての職務に対する誇り。
彼らは道化のショーに出演しに来たのではない。法に基づき、帳簿の真実を確定させるためにここにいた。

カメラは、鬼頭たちが淡々と電卓を叩き、領収書の一枚一枚と銀行取引明細を突き合わせる緊迫した臨検の様子を、遠巻きのノーカット長回しで捉え続けていた。

その横で――Pがマイクを握りしめ、巨大プロジェクターの前に進み出た。

「――全国の視聴者の皆様。そして、オレを『犯罪者』と罵ったすべての方々へ」

Pの声は、震えていなかった。
薄暗いオフィスでカップ麺をすすっていた社内便利屋のおじさんの顔は、そこにはなかった。
自らの恥と肉体を削り落として生きてきた、本物の表現者の眼光だった。

「オレが先月十五日、秋葉原の十七歳の少女を事務所に連れ込み、淫行におよんだという『週刊文真』の記事について、今から動かぬ証拠を開示します」

バチィンッ！
プロジェクターのスクリーンに、巨大な高解像度映像が映し出された。

Pの自作AIシステム『Sentinel-AI』が記録していた、先月十五日午後九時から十一時の上野オフィスの秒単位の全方位監視ログ。

画面の中のPは、薄汚れたスラックスを履き、猫背でキーボードを叩き、湯気を立てるカップ焼きそばにマヨネーズを絞り、必死に頬張っていた。
誰一人として事務所に入ってきた形跡はない。
スマートロックの施錠ログ、生体認証の一致率、そして画面の右隅にリアルタイムで検証されるブロックチェーンのトランザクションハッシュ値。

「これが、事件当夜のオレのすべてです」
Pは静かに告げた。
「このログデータは、外部のパブリックチェーンに秒単位で刻まれており、オレはおろか世界中のいかなるハッカーであっても、後から一ミリたりとも改ざんすることは物理的に不可能です。オレはあの日、一人でカップ焼きそばを食い、コードを書いていただけです」

チャット欄の空気が、一瞬で凍りついた。

――『おい……マジで一人で焼きそば食ってるだけじゃん……』
――『ブロックチェーンのハッシュ検証が完全に通ってるぞ。これ改ざん不可能なやつだ』
――『じゃあ……あの週刊誌の記事は何だったんだ！？』

「それだけではありません」
Pは続けて、次の音声ファイルを再生した。

スピーカーから響き渡ったのは――あの六本木の半グレブローカー・佐々木の下卑た怒声だった。

『――おいユイ、分かってんだろうな。お前の親父の借金八十万、チャラにして欲しかったら、この紙に書いてある通りに記者に喋れ。“Pに無理やり服を脱がされた”って泣きながら言え。しくじったら、お前の実家もタダじゃ置かねえぞ』

続いて再生されたのは、救出された少女ユイの、涙ながらの自首調書と警察への被害届の受領証だった。

スタジオが、そしてネットの海が、巨大な怒りの津波に飲み込まれた。

――『佐々木って奴、完全にアウトだろ！！』
――『でっち上げのハニートラップかよ！ 最低すぎる！！』
――『週刊文真、廃刊しろ！ 人の人生を何だと思ってんだ！！』
――『Pさん……疑って本当にごめんなさい……！』

二百万人の手のひら返し。
だが、Pの戦いはまだ終わっていなかった。
最も巨大な壁――国家権力による「脱税の嫌疑」の決着が残されていたのだ。

#### ［３：公文書の宣告と、黒幕の崩壊］

午後九時十五分。
パーテーションの奥で、すべての帳簿と通帳、そして海外決済ゲートウェイのログを照合し終えた鬼頭統括官が、静かに眼鏡を外した。

スタジオの照明が、一瞬、静まり返った。
二百万人の視聴者が、息を呑んでモニターを見つめていた。

鬼頭は立ち上がり、神崎弁護士に向き直った。
その顔には、一切の感情の揺らぎはなかった。だが、その瞳の奥には、脱税を暴けなかった悔しさではなく、非の打ち所のない完璧な経理防壁に対する、プロフェッショナルとしての深い敬意が宿っていた。

鬼頭は一枚の公文書を、神崎弁護士に手渡した。

『差押処分解除通知書　および　調査結果通知書』

そして、鬼頭はマイクを手に取ることはせず、神崎弁護士に向かって、スタジオ中に通る重厚な声で事務的に告げた。

「……合同会社P-PROJECTに対する査察調査を終了する。
全取引明細、電子帳簿、および損金算入の根拠資料を精査した結果、所得隠し、架空外注、脱税の事実は一切認められない。
すべての資産に対する保全差押えを、本日付で即時解除する。
――申告是認（シロ）だ」

鬼頭はそう言い放つと、部下たちに合図を送り、カメラに一瞥もくれることなく、整然とスタジオの出口へと歩み去っていった。
国家公務員の厳格な誇りを守り抜いた、完全なる「シロ」の証明。

神崎弁護士が、その公文書を両手で掲げ、カメラの前に突き出した。

「――勝訴です！ 東京国税局査察部による、完全なる無実の公認が下されました！！」

ウォオオオオオオオオオオオオオッッッッ！！！！

スタジオのスタッフ、タカシ、そしてチャット欄が、狂乱の歓喜で爆発した。

さらにその数秒後、タカシのスマホに警視庁からの緊急連絡が入った。
「Pさん！ 佐々木と週刊誌の買収記者が、六本木のビルから逃亡しようとしたところを、警視庁組対と捜査一課が強要未遂・偽証教唆・名誉毀損の現行犯で逮捕したそうです！！」

完全勝利。
泥水の中から始まった小さなピエロ劇が、国家権力と裏社会の巨大な陰謀を、完全なる合法と技術の力で叩き潰した奇跡の瞬間だった。

だが――。
スタジオの熱気は、そこで収まるどころか、更なる狂乱の極限へと突き進もうとしていた。

画面を埋め尽くすチャット欄の二百万人の視聴者が、次なる「儀式」を求めて狂ったように叫び始めたのだ。

――『P！ 濡れ衣晴れたぞ！！』
――『で……Pは熱湯に落ちないの？w』
――『勝ったんだから落ちろよ！！w』
――『四十四・五度の熱湯が呼んでるぞ！！w』

男たちの本当の戴冠式が、いま幕を開けようとしていた。
