# 携帯小説『アングラ・バカロード』
## 第4章：熱湯の審判：ピエロの戴冠（完結編）
### 【第4話】夜の街の反乱（女帝カオルの大反転攻勢）

---

#### ［１：深夜の歌舞伎町、女帝の殴り込み］

午前二時十五分。
雨に濡れた歌舞伎町の最深部、花道通り沿いの雑居ビルの地下駐車場。

薄暗いコンクリートの空間に、黒塗りのセンチュリーとアルファードが二台、音もなく滑り込んだ。
ドアが開き、降りてきたのはトレンチコートを着たカオルと、神崎弁護士、そして吉原の大手グループの系列警備会社に所属する屈強な男たち四人だった。

「カオルさん、間違いありません」
神崎弁護士がタブレットのGPS画面を示した。
「佐々木の息のかかったスカウト会社の管理マンション、地下のトランクルーム奥の事務所です。ユイという少女は、そこに軟禁状態に置かれています」

カオルは無言で煙草の火を消し、ルブタンのヒールを鳴らして地下の通用口へと歩を進めた。
防犯カメラのインターホンを鳴らすまでもなく、警備の男たちが頑丈なマスターキーで鉄扉を解錠し、一気に踏み込んだ。

「だ、誰だテメエら……！」

ソファでたむろしていた佐々木の手下の若いチンピラ二人が飛び起きた。
だが、神崎弁護士が警察手帳ならぬ弁護士バッジを掲げ、冷然と言い放った。

「警視庁組織犯罪対策部、および新宿警察署生活安全課に通報済みです。捜査員がすでにビルを取り囲んでいます。不法監禁、強要罪、未成年者誘拐の現行犯で逮捕されたくなければ、全員その場に伏せなさい」

「ひっ……！」
チンピラたちが腰を抜かし、両手を挙げた。

奥の小部屋のドアを開けると、そこにはパイプベッドの上で毛布にくるまり、怯えきった目で震えている一人の少女がいた。
秋葉原のコンカフェ店員・ユイ（十七歳）。

カオルはベッドの前に歩み寄り、優しく少女の肩に手を置いた。

「……怖かったわね、ユイちゃん。もう大丈夫よ。アタシが来たから」

少女はカオルの顔を見上げた瞬間、堰を切ったように大粒の涙をこぼした。
「カ、カオルさん……！ ごめんなさい……！ あたし、嘘をついたんです……！
お母さんの借金八十万円をチャラにしてやるから、言われた通りのシナリオを読めって佐々木さんに脅されて……！
Pさんには……会ったこともないのに……！」

カオルは少女を強く抱きしめ、背中を優しくさすった。

「いいのよ。アンタのせいじゃない。悪いのは、アンタみたいな弱い子供をダシにして、他人の人生を奪おうとした腐った大人たちよ」

神崎弁護士がICレコーダーを起動し、少女の自白音声、そして佐々木が少女を脅迫していたLINEのトーク履歴の完全な電磁的バックアップを採取した。
決定的な物証が、女帝の手によって回収された瞬間だった。

#### ［２：改ざん不能のハッシュ値、AIが証明した潔白］

同じ頃。
鶯谷のホテルの一室で、オレは安物のノートPCに向かい、キーボードを猛烈な勢いで叩いていた。

「……よし、復元完了だ」

画面に展開されたのは、オレがオフィスと千葉の特設スタジオに独自に構築していた、完全分散型のセキュリティ監視システム『Sentinel-AI』のアーカイブデータだった。

週刊誌の記事で、オレが少女を事務所に連れ込んで淫行におよんだとされる日時は――先月十五日の午後九時から十一時。

だが、Sentinel-AIが記録していた高精度4K映像ログには、こう記録されていた。

```
［ 2026/11/15 21:03:12 ］
上野オフィス・第1編集ブース：山田大介、入室。
生体認証ログ一致率：99.8%
行動認識：カップ焼きそば（大盛り）にお湯を注ぐ動作を検知。
作業ログ：Pythonスクリプト（モザイク追従アルゴリズム）のデバッグ作業を継続。

［ 2026/11/15 22:45:30 ］
山田大介、椅子を並べて仮眠を開始。
外部からの入室者：0名（全入退室スマートロック施錠状態）
タイムスタンプ検証：ブロックチェーンハッシュ値整合性 100% OK
```

秒単位の映像。
キーボードのタイピングログ。
スマートロックの開閉履歴。
そして何より――このログデータは、生成された瞬間に外部のパブリック・ブロックチェーンにハッシュ値が刻まれており、後から一秒たりとも改ざんすることが物理的に不可能な「電磁的アリバイ」だった。

「Pさん……！ これ、完璧じゃないですか！」
タカシが画面を食い入るように見つめ、叫んだ。
「事件のあった時間に、Pさんはカップ焼きそば食ってコード書いて寝てただけだ！ 女の子なんか事務所の一歩手前にも来てない！」

「ああ。これが、オタクが培ってきた技術の盾だ」
オレはUSBメモリを握りしめた。
「だが……これだけじゃ足りない。ネットに溢れかえった悪意の濁流は、客観的証拠を提示しただけでは『偽造動画だ』と騒いで終わる。
世論の心臓を直接貫く、本物の『声』が必要なんだ」

その時、ホテルのドアが開き、カオルが戻ってきた。
その背後には、神崎弁護士と、保護されたユイの姿があった。

「物証と自首調書は揃ったわ」
カオルは冷徹に言い放った。
「さあ……次は、アタシたちの番よ。夜の街の女たちを舐めた代償を、あのマスゴミとチンピラ共に教えてあげるわ」

#### ［３：夜の街の反乱、五百万人の蜂起］

午前四時。
静まり返った夜の帳を破り、日本のSNS空間で、前代未聞の「大規模反乱」が勃発した。

発火点は、六本木の頂点に君臨するラウンジ嬢・エリカのInstagramアカウントだった。
フォロワー数八十万人。
普段は高級ホテルのラウンジやハイブランドのバッグの写真しか投稿しないエリカが、一切のフィルターを外したすっぴんの素顔で、一本の動画を投稿したのだ。

『週刊誌の記事を見て、あまりに腹が立ったので言います。
Pさんが未成年を監禁した？ 淫行した？
全部デマです。嘘っぱちです。
あたしはPさんの番組で、四十四度の熱湯に落とされました。メイクも落とされて、恥も全部晒しました。
でもね――Pさんは、収録の前も後も、一度だってあたしたちキャストの身体に指一本触れなかった。
誰よりも腰が低くて、誰よりもオドオドしてて、誰よりもあたしたち夜職の人間のプライドを守ってくれた人です。
あたしたちが命懸けで作った番組を、汚い金儲けのために踏みにじるな！』

エリカの投稿の数分後、今度は吉原のソープ嬢・狂犬のレイナがX（Twitter）に動画を投下した。

『おい、週刊文真のクソ記者共！ よく聞け！
Pさんはな、バカだしハゲだし情けないおっさんだけど、女の子を騙して泣かせるような男じゃねえんだよ！
泥水すすって、客に頭下げて、何千万も税金払って生きてるあたしたちを、一番リスペクトしてくれたのがあのハゲなんだよ！
あいつをハメた黒幕の半グレ共、あたしたち吉原を本気で怒らせたらどうなるか、分からせてやっからな！』

さらに、川崎、西川口、すすきの、歌舞伎町、ミナミ、中洲……。
全国のキャバクラ、風俗、コンカフェで働くキャストたち、そして『アングラ・バカロード杯』に出演した数十人のインフルエンサーたちが、一斉に立ち上がった。

ハッシュタグ『#Pさんはピエロだけどクリーン』『#夜の街を舐めるな』。

総フォロワー数にして【五百万人】を超える、夜の街の女たちの怒りの声が、瞬く間にXのタイムラインを埋め尽くした。
それは、作られたプロパガンダではない。
自らの恥を晒し、熱湯の中で誇りを分かち合った者たちによる、生々しく純粋な「魂の擁護」だった。

タイムラインの流れが、目に見えて変わり始めた。

――『エリカ様がすっぴんで怒ってる……マジでガチじゃん』
――『吉原のレイナの動画、迫力が違いすぎる。これ嘘ついてる側の熱量じゃないだろ』
――『週刊誌の記事、証拠の音声が切り貼りっぽかったし、怪しくないか？』
――『Pさん、もしかして本当にハメられたのか……？』

デジタル・リンチの分厚い氷壁に、巨大な亀裂が入った。
だが――疑惑を完全に粉砕し、国家権力と世論のすべてをひっくり返すためには、まだ最後の決定打が残されていた。

オレはスマホを手に取り、ある人物の番号をコールした。
東京国税局査察部・鬼頭統括官の直通携帯だった。

「……もしもし。鬼頭統括官ですね。山田です」

受話器の向こうで、鬼頭が息を呑む配下の音が聞こえた。

「お前に提案があります。
オレたちの無実を、そして貴庁が疑っている脱税の嫌疑を――全世界が見守る前で、完全決着させましょう」

舞台は整った。
千葉の特注熱湯スタジオにて、前代未聞の「最終決戦」の火蓋が切られようとしていた。
