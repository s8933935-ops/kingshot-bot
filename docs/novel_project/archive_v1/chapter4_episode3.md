# 携帯小説『アングラ・バカロード』
## 第4章：熱湯の審判：ピエロの戴冠（完結編）

#### ［１：残高ゼロの暗闇、止まるインフラ］

ピピッ、ピピッ……。
『エラーコード：E-403　お取り扱いできません』

上野駅前のメガバンクのATMコーナー。
冷たい蛍光灯の下で、キャッシュカードが吐き出された。
記帳された通帳の最終行には、無機質な印字が並んでいた。

```
2026/12/15  差押（東京国税局）    - 142,500,000
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
現在残高：                                 0 円
```

ゼロ。
一円の端数すら残らず、合同会社P-PROJECTの全法人口座、そして山田大介名義の個人口座に至るまで、すべての残高が【0円】へと吸い上げられていた。

国税通則法第138条に基づく「滞納処分免脱防止のための緊急保全差押え」。
裁判所の令状一枚で、銀行のシステムは一切の抗弁を受け付けず、瞬時に個人の血流を止める。

それだけではなかった。
スマホを開くと、連携していた法人クレジットカードの利用停止通知がずらりと並んでいた。

『【AWS】月額利用料金（2,840,000円）のお支払いに失敗しました』
『【Cloudflare】CDNサービスの決済が確認できません』
『【エックスサーバー】ドメイン更新エラー』
『【野田倉庫管理】スタジオ賃料（1,200,000円）未納のお知らせ』

「……あと、五日だな」
オレは冷え切った自販機の前で呟いた。

独自会員制サロン『VIP CLUB』を支えるAWSのストリーミングサーバーは、決済失敗から七日間の猶予期間を過ぎれば、容赦なく自動でインスタンスをシャットダウンする。
サーバーが止まれば、七万人の会員への配信は途絶え、二階建てファネルの心臓部は完全に停止する。
千葉の特注熱湯水槽スタジオも、賃料未払いで鍵を替えられれば立ち入り禁止になる。

手元にある現金は、オレの財布に残っていた三千四百円と、タカシが握りしめていた小銭の五百円玉が二枚。
月商一億円を誇った巨大要塞の軍資金は、わずか二十四時間で、四千四百円の灰へと消え去っていた。

#### ［２：鶯谷の安ホテル、ピエロの原点］

上野のオフィスの周囲には、すでにカメラを構えた突撃系YouTuberや週刊誌の張り込み記者が群がり、とても近づける状態ではなかった。
オレとタカシは、フードを目深にかぶり、夜の山手線に乗って一駅隣の鶯谷へと逃げ延びた。

駅前の路地裏、かつてPがマジックテープの財布を落とし、ドブ板につまずいて転んだあの懐かしい街。
一泊四千円の、窓のない狭いビジネスホテルのシングルルーム。
パイプベッドが一つと、擦り切れたカーペット。
暖房の効きの悪い部屋の中で、タカシは壁に背中を預け、膝を抱えて小刻みに震えていた。

「……Pさん。もう逃げましょうよ」

タカシの掠れた声が、湿った部屋に落ちた。
充血した目は落ち窪み、数日間で頬はげっそりと削げていた。

「佐々木の言う通り、権利を全部渡して土下座しましょう……。
相手はヤクザと繋がってる半グレで、テレビ業界の巨大プロで、国家権力のマルサなんすよ……！？
オレたちみたいな素人のオタクと借金まみれのクズが、勝てるわけないじゃないですか……！
オレ、もう刑務所に行くのも、実家に火をつけられるのも嫌っすよ……！」

タカシは顔を覆い、子供のように声を殺して泣いた。
二十一歳の若者だ。ここまでついてきてくれたこと自体が、奇跡のようなものだった。

オレは自販機で買ってきた、温かい缶コーヒーをタカシの冷たい手のひらに握らせた。
そして、ベッドの端に腰掛け、静かに天井のシミを見つめた。

「タカシ。君は……オレがなぜ、このアングラの世界に飛び込んだか知ってるか？」

タカシは鼻をすすりながら、涙で濡れた顔を上げた。
「え……？ 金を稼ぐため……じゃないんすか？」

「金なんて、後からついてきたオマケだよ」
オレは自嘲するように小さく笑った。

「オレはね、三十九年間、誰からも名前を呼ばれない透明人間だったんだ。
会社の書類棚の隅で、壊れたプリンターの紙詰まりを直して、若い女子社員に『おい、おじさん』としか呼ばれなかった。
誰にも愛されず、誰の記憶にも残らず、ただ安い炭水化物を胃袋に流し込んで、死んだら無縁仏として焼かれるだけのごみ屑だった。
それが……悔しくて、死ぬほど悔しくてたまらなかったんだ」

オレは胸ポケットから、ボロボロの大学ノートを取り出した。
第0話のあの夜、鶯谷の寒風の中で、ボールペンのペン先が紙を突き破るほどの筆圧で書き殴った、最初のメモ。

――【死んでも諦めるな。オレは絶対に、この時代に爪痕を残す】

「オレは最初から、何も持っていなかったんだよ、タカシ。
金も、社会的信用も、名誉も、最初から一ミリも持っていなかった。
失うものなんて、最初から何一つないんだ」

オレは立ち上がり、タカシの肩に手を置いた。

「ピエロってのはな……綺麗な衣装を着て、客から拍手をもらっている時が本番じゃないんだ。
衣装を剥ぎ取られ、泥水をぶっかけられ、全員から石を投げられて、真っ裸で舞台の上に放り出された時……
そこで、ニッと笑って見せる無様な姿こそが、世界で一番強い道化の真骨頂なんだよ」

タカシが、息を呑んでオレの顔を見つめていた。
その瞳の奥に、かつて御徒町の地下喫茶で見た「深海魚のように昏く、だが絶対に消えない狂気の炎」が、再び宿るのが見えた。

その時だった。

コン、コン。

ホテルの薄いドアが、正確に二回、小気味よいリズムでノックされた。

#### ［３：女帝の降臨と、冷徹な逆襲の狼煙］

ガチャリ。
チェーンをかけたまますき間を開けると、そこには冬の夜の冷気とともに、あまりにも懐かしく、そして圧倒的な香水の香りが漂ってきた。

「……何よ、その情けない顔は」

ドアの向こうに立っていたのは、濡羽色のトレンチコートに身を包んだカオルだった。
足元には、相変わらず一寸の曇りもないルブタンのハイヒール。
手には、高級ブランドのレザーバッグと、神崎弁護士の事務所の刻印が入った分厚いアタッシェケース。

「カ、カオルさん……！？ なんでここが……！？」
タカシが叫んだ。

「アンタたちが鶯谷のこのホテルに逃げ込むことくらい、お見通しよ」
カオルはチェーンを外させ、躊躇なく狭い部屋に入ってくると、パイプベッドの上にドンとアタッシェケースを置いた。

「国税のガサ入れに、週刊誌のデマ記事、それに佐々木の脅迫電話ね。
全部、神崎先生から報告を受けてるわ」

カオルは腕を組み、仁王立ちになってオレたちを見下ろした。
その瞳には、恐怖も動揺も、一欠片の絶望すら存在していなかった。
そこにあったのは――夜の頂点を五年間守り抜いてきた女帝特有の、冷徹で、獰猛な「獲物を仕留める獣の光」だった。

「アタシを誰だと思ってんの。吉原の女帝よ。
政財界の重鎮から裏社会の首領まで、何百人もの男の騙し合いと修羅場をくぐり抜けてきたのよ。
六本木のチンピラと三流週刊誌が結託した程度の安っぽい罠に、アタシが慌てると思ってんの？」

カオルはアタッシェケースの留め金をパチンと弾いて開けた。
中から現れたのは、整然と並べられた書類の束、そしてICレコーダーだった。

「反撃の準備は、すべて整えたわ」
カオルは不敵な笑みを浮かべた。

「あのチンピラ共、アタシの縄張りの男に手を出したことを、骨の髄まで後悔させてやるわ。
……行くわよ、P、タカシ。
夜の街の本当の力を見せてあげるわ」

絶望の極寒の中に、巨大な逆襲の炎が上がった。
ピエロと女帝の、世界を覆す大反乱の幕が、静かに切って落とされた。
