# 携帯小説『アングラ・バカロード』
## 第2章：二階建ての城と、札束の窒息
### 【第2話】パンクするオタクと、女房役の降臨（超濃密・文庫完全版）

---

#### ［１：個人口座の怪獣と、税務署の死神］

ヒュー、ヒュー……。

六畳一間のアパートの床で、オレは膝を抱え、浅い呼吸を繰り返していた。
過呼吸だった。
胸が苦しく、指先が痺れて感覚がなくなっていく。

目の前に転がっているのは、メガバンクのプラスチック製キャッシュカードと、記帳を終えたばかりの通帳。
そこに印字されていた数字を見た瞬間、オレの精神の許容量は完全に破裂した。

```
2026/11/25  Google LLC (YouTube)    + 4,820,300
2026/11/26  振込 カブシキガイシャ○○  + 3,300,000
2026/11/27  振込 クラブ××            + 5,500,000
2026/11/28  振込 ユウゲンガイシャ△△  + 3,300,000
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
現在残高：                         32,450,120 円
```

三千二百万円。
手取り二十一万三千円、先月まで電気代七千八百円が払えずに本気で泣いていた中年男の個人口座に、わずか一週間で三千万円を超える大金が流れ込んでいたのだ。

だが――それは幸福などではなかった。
それは、何の知識も防壁も持たない素人の首を絞め上げる、凶悪な絞首刑の縄だった。

「……Pさん、大丈夫っすか？ 水、飲みますか？」
隣でタカシが怯えた顔でペットボトルを差し出してくる。
タカシの手には、今日アパートの郵便受けに放り込まれていた、差出人不明の白い封筒が握られていた。

中に入っていたのは、一枚の便箋。
パソコンのワープロ文字で、こう印字されていた。

『P様。先日の佐々木との件、いかがお過ごしでしょうか。今週金曜日の午後八時、六本木の事務所にて正式な契約書をご用意しております。もしご足労いただけない場合、御社……いや、貴殿の勤務先である○○商事およびご実家の皆様へ、直接ご挨拶に伺うことになります』

「実家……勤務先……」
歯の根が合わず、ガチガチと音を立てて震えた。
オレの本名も、昼間の勤務先も、田舎の実家の住所まで、半グレたちはすでに調べ上げていたのだ。

それだけではなかった。
ネットで「個人事業主　急激な売上　税金」と検索した結果が、オレの息の根を止めにかかっていた。
個人名義の口座に三千万円以上の売上が入った場合、所得税の最高税率区分（45%）に達し、さらに住民税（10%）、個人事業税、そして消費税の納税義務が発生する。
翌年の春、オレの手元には【約二千万円】という天文学的な納税通知書が届くのだ。

もし、この金を無邪気に使ってしまっていたら？
あるいは半グレに三割ピンハネされ、手元に金が残っていなかったら？
オレは脱税犯として国税査察官に手錠をかけられ、刑務所の冷たいコンクリートの上に叩き込まれる。

「死ぬ……。オレ、殺されるか逮捕される……！」
頭を抱えて呻くオレの横で、アパートの安っぽいチャイムが、無機質に鳴り響いた。

ピンポーーーン。

ヒッ、とタカシが短い悲鳴を上げて飛び退いた。
「ま、まさか……佐々木の奴らじゃ……！？」

---

#### ［２：黒塗りの要塞と、女帝の凱旋］

チャイムは、迷いのないリズムで二度、三度と鳴らされた。

ガチャリ。
鍵を開けてドアを押し開けた瞬間、薄暗いアパートの共用廊下に、あまりにも不釣り合いな光景が広がっていた。

「……何よ、その見苦しい格好は」

そこに立っていたのは、カオルだった。
濡羽色のトレンチコートを羽織り、足元には艶やかなクリスチャン・ルブタンのハイヒール。
吉原のVIPルームで見せた妖艶な和装とは一変し、まるで外資系投資銀行の敏腕女性役員のような、圧倒的なオーラを放っていた。

だが、驚くべきは彼女一人ではなかった。
カオルの背後には、仕立ての良いグレーのスリーピーススーツを着た初老の紳士と、銀縁メガネをかけた知的な四十代の男が、重厚な革のアタッシェケースを手にして整列していたのだ。

「カ、カオルさん……！？ なんでここが……」

「アンタの身元くらい、吉原のネットワークを使えば三十分で割れるわよ」
カオルは躊躇なく土足で玄関に踏み込み、散らかった部屋を一瞥した。
カップ麺の空き容器、エナジードリンクの缶、そして床に放り出された三千二百万円の通帳と半グレからの脅迫状。

カオルはしゃがみ込み、細い指先で脅迫状を摘み上げた。
そして、フッと冷笑を漏らした。

「……佐々木ね。六本木のケツの青いチンピラが、調子に乗ってアタシの縄張りの男に手を出そうとしてるわけね」

カオルは脅迫状をクシャリと丸め、ゴミ箱に放り込んだ。
そして、床にへたり込んでいるオレの前に仁王立ちになり、腕を組んで見下ろしてきた。

「アンタ、完全にパンクしてるわね。過呼吸起こして、今にも胃酸吐いて死にそうな顔してるじゃない」

「だ、だって……口座に三千万円も入ってきて……税金がいくらかかるかも分からなくて……それに反社の男たちが実家に行くと……！」

オレは涙目で訴えた。
三十九歳の男が、十歳も年下の女の前で、情けなく醜態を晒していた。

カオルは深いため息を一つ吐くと、背後の二人の男に向かってアゴをしゃくった。

「先生方。この哀れなピエロに、現実を教えてあげてください」

#### ［３：二人の盾――法律と税務のプロフェッショナル］

グレーのスリーピーススーツの初老の紳士が一歩前に出て、胸ポケットから名刺を差し出した。

『弁護士法人○○総合法律事務所　代表弁護士　神崎修一郎』

名刺の肩書を見た瞬間、オレの呼吸が止まりそうになった。
テレビのニュース番組で、企業の大型買収や危機管理の解説者として何度も見かけたことのある、日本屈指の企業法務・刑事弁護のトップランナーだった。

「神崎です。カオルさんからの依頼で参りました」
神崎弁護士は穏やかな、だが芯の通った重厚な声で言った。
「まず、佐々木と名乗る人物からの接触についてですが、ご安心ください。すでに警視庁組織犯罪対策部（組対）の担当官と連絡を取り、防犯登録を済ませました。明日、私の事務所名で、佐々木らの会社宛てに『受任通知』および『接近禁止・強要罪に関する警告書』を内容証明郵便で発送します。彼らは所詮、看板のない半グレです。一流の法曹と警察が介入した案件には、絶対に手を出せません」

「け、警察と弁護士……！？」
タカシが目を丸くした。

続いて、銀縁メガネの男が進み出た。
『税理士法人××パートナーズ　代表公認会計士・税理士　水野誠』

「税務について解説いたします」
水野税理士はタブレット端末を開き、鮮やかなグラフを提示した。
「現在の個人口座への着金状況は、極めて危険です。このまま年を越せば、最高税率での所得税および無申告加算税のリスクが発生します。解決策は一つ――【合同会社】の即日設立です」

水野税理士は淀みなくスキームを解説した。
「明日付で、資本金五百万円のコンテンツ制作会社を登記します。YouTubeの収益受取口座およびタイアップ広告の契約主体をすべて法人へと移行。役員報酬の適正設計、旅費日当規程の導入、そして機材購入費や取材費（飲食代）の全額損金算入により、実効税率を約30%前後に圧縮します。納税資金は別口座に自動プールし、税務署からの査察が入っても一円の瑕疵もない完全な防壁を構築します」

魔法のようだった。
オレの頭を破裂させ、死の淵まで追い詰めていた「暴力」と「税金」という二大怪獣が、この二人のプロの手によって、わずか十分で綺麗に解体されてしまったのだ。

「す、すごい……。でも、こんなトップの先生たちにお願いしたら、着手金だけでも数百万円は……」

オレがおずおずと呟くと、カオルがクスッと笑った。

「先生方への顧問料は、アタシがもう全額前払いで済ませてあるわよ」

「え……！？ カオルさんが……！？」

#### ［４：アングラ同盟の真の契り］

部屋の中に、再び静寂が戻った。
弁護士と税理士の二人は、一礼すると手際よく書類をまとめ、静かにアパートを後にした。

六畳一間の部屋に残されたのは、オレと、タカシと、カオルの三人だけだった。

カオルは窓際のパイプ椅子に腰掛け、細い脚を組み直した。
そして、オレの顔をじっと見つめ、静かに口を開いた。

「……言ったでしょ、吉原で。『数字が出たら、次のビジネスの話をしてあげる』って」

カオルの瞳の奥に、夜の頂点を極めた女特有の、冷徹で、だが底知れぬ覚悟を宿した炎が揺らめいていた。

「アタシはね、吉原で五年間、何百人もの男たちの興亡を見てきたの。株で当てた男、ITで成金になった男、アングラで大金を掴んだ男……。みんなね、最初は威勢がいいのよ。でも、自分の器以上の金を持った瞬間、調子に乗って女に貢ぐか、怪しい投資話に騙されるか、税務署に踏み込まれて一瞬で消えていくの」

カオルは前屈みになり、オレの瞳を射抜いた。

「アンタも同じよ。技術は天才的、コンテンツの嗅覚も狂ってる。でも――金と組織の管理に関しては、救いようのないド素人の赤ん坊よ。アンタみたいなバカ、放っておいたら脱税で捕まるか、半グレに乗っ取られて東京湾の藻屑になるに決まってる」

息を呑んだ。
痛烈な言葉だった。だが、一言一句、すべてが真実だった。

カオルはバッグから、一枚の契約書を取り出し、座卓の上にスッと差し出した。

『合同会社P-PROJECT　業務執行および財務統括に関する合意書』

そこには、流麗な文字で、こう記されていた。
代表社員：P（制作・出演統括）
最高財務責任者（CFO）：カオル（財務・法務・営業統括）
議決権および利益配分：P 50% / カオル 50%

「いいわ。乗ってあげる」
カオルは不敵な笑みを浮かべた。
「その代わり――アンタの看板に一ミリでも泥を塗ったら、本当に許さないからね。
そして、この会社の財務、口座管理、契約の締結……これからは全部、アタシが仕切るわ。アンタには、金勘定の心配なんて一秒もさせない」

カオルは身を乗り出し、オレの胸元を指差した。

「アンタはただ、パソコンの前で狂気的な動画を作ることだけに集中しなさい。
夜の街の泥水の中で、情けなく頭を下げて、熱湯に落ちて、日本中の人間を笑わせなさい。
アンタが稼いできた血と泥の札束は――アタシが世界一硬い金庫の中で、一円も減らさずに増やしてあげるから」

胸の奥が、熱く震えた。
それは、恋愛感情などという生易しいものではなかった。
地獄の底で出会った、魂の共犯者。
弱点を補い合い、時代の頂点をもぎ取るための、完全なる「アングラ同盟」の成立だった。

オレは震える手でペンを取り、契約書の署名欄に、自分の本名を力強く刻み込んだ。

「……よろしくお願いします、カオルさん。オレの命も、チャンネルも……全部預けます」

カオルは満足げに目を細め、契約書を回収した。

「決まりね。じゃあ、次の仕事よ。
まずは――六本木と歌舞伎町から届いてる五百万円のオファー、全部蹴っ飛ばしなさい」

「えっ！？ け、蹴るんですか！？」
タカシが叫んだ。

「当たり前でしょ」
カオルは冷笑を浮かべた。
「あんな小銭のタイアップで消耗してる暇なんてないのよ。アタシたちが目指すのは――月商一億円の、誰にも邪魔されない巨大な城よ」

狂気の天才オタクと、夜の街の女帝。
二人の怪物が手を組んだその瞬間から、アングラYouTube界の常識を根底から覆す、前代未聞の大進撃が幕を開けた。
