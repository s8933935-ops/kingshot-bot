# 携帯小説『アングラ・バカロード』
## 第4章：熱湯の審判：ピエロの戴冠（完結編）
### 【第2話】デジタル・リンチ（仕組まれた週刊誌の爆弾）

---

#### ［１：正午十二時、ネットの処刑台］

午後零時。
正午の時報とともに、ネットの深淵に投げ込まれた巨大な焼夷弾が、一瞬で炎の嵐となって日本中を焼き尽くし始めた。

大手週刊誌『週刊文真』の公式Webニュースサイト。
そのトップページに、血のような赤文字で躍り出た特報の見出し――。

```
【独占スクープ・音声入手】
月商1億の闇エンタメYouTuber「P」の仮面を剥ぐ！
17歳女子高生コンカフェ店員への「卑劣な淫行と薬物監禁」の全貌
実名：山田大介（39）――夜の街を牛耳る男の知られざる狂気
```

記事を開いた瞬間、息が止まりそうになった。

そこには、オレの会社員時代の古い社員証の写真、そして最近撮られたらしい、上野のオフィスに入っていくオレの無防備な顔写真が、モザイクなしでデカデカと掲載されていた。
そして、記事の冒頭に埋め込まれていたのは――一本の音声ファイルだった。

『……怖かったです。Pさんは、動画のオーディションだと言って私を事務所の奥の部屋に連れ込んで……お酒を無理やり飲まされて……逃げようとしたら腕を掴まれて……「俺の言うことを聞かないと、この街で働けなくしてやる」って……』

咽び泣く、あどけない少女の声。
記事には、秋葉原の有名コンカフェに勤務する高校三年生の少女・ユイ（十七歳）の告発手記が、数千文字にわたって克明に綴られていた。
日付、場所、密室の状況、そして「無理矢理に身体を弄ばれた」という、あまりにも生々しく悍ましい記述の数々。

もちろん――完全なる、100%の虚構。
オレは秋葉原のコンカフェの取材など一度もしたことがないし、未成年の女の子を事務所に一人で入れたことなど天地神明に誓って一度たりともなかった。

だが――ネットの法廷において、「真実」などというものは最初から何の意味も持たなかった。

#### ［２：猛威を振るうデジタルの火あぶり］

ブブブブブブブッ……！
スマホのバイブレーションが、狂った心電図のように止まることなくデスクの上で暴れ回っていた。

X（Twitter）のトレンドランキング。
1位：#P逮捕
2位：#山田大介
3位：#アングラYouTuber性加害
4位：#アングラバカロード即刻BAN
5位：#週刊文真

タイムラインを更新するたびに、数万件の呪詛と罵倒が雪崩のように流れ込んでくる。

――『うわ、このおっさんマジで気持ち悪すぎる。最初からただの変質者だと思ってたわ』
――『女子高生に手を出して月商1億とか、人間のクズの極み。今すぐ死刑にしろ』
――『YouTubeはなんでこんな犯罪者のチャンネル放置してんの？ Googleに通報祭りしようぜ』
――『情けないピエロのフリして、裏で未成年食い散らかしてたんか。反吐が出る』
――『住所特定されたぞ。上野の○○ビル3階。凸（突撃）行こうぜ』

YouTubeの管理画面（YouTube Studio）のリアルタイムダッシュボード。
登録者数【七十二万人】を誇っていたチャンネルの数字が、目に見えるスピードで、滝のように削り取られていた。

マイナス千人。
マイナス五千人。
マイナス一万人。
マイナス三万人。

わずか一時間で、十万人以上の登録者が一斉に登録を解除していった。
コメント欄には、数秒おきに何千件もの「死ね」「消えろ」「逮捕されろ」という定型句が書き殴られ、サーバーのモデレーションフィルターがパンクしてクラッシュした。

さらに――TikTokやYouTubeショートには、すでに数十人の「暴露系YouTuber」や「切り抜き職人」たちが、オレの顔写真をサムネイルにして『【速報】P、ガチで逮捕秒読み！ 淫行の音声がヤバすぎる！』といった煽り動画を量産し、それぞれ数十万再生を叩き出して荒稼ぎしていた。

他人の人生が燃え盛る火の中に、油を注いで小銭を稼ぐ現代のハイエナたち。
かつてオレたちが熱狂の渦を巻き起こしたその同じアルゴリズムが、今度はオレたちを骨の髄まで焼き尽くす処刑台へと変貌していたのだ。

#### ［３：二億四千万円の違約金と、黒幕の嘲笑］

プルルルルルッ！ プルルルルルッ！
オフィスの固定電話が、引きちぎれんばかりに鳴り響いていた。

査察官たちが段ボール箱を運び出したあとの、荒れ果てた部屋。
受話器を取るまでもなく、ファックスからカタカタと紙が吐き出され、床の上に積み上がっていく。

『契約解除通知書　および損害賠償請求書』
『貴殿の不祥事および重大な社会的信用の毀損に伴い、契約第12条に基づき、スポンサー契約を即日解除いたします。つきましては、違約金として【金30,000,000円】の支払いを求めます』

『六本木○○グループ：提携解除通知。損害賠償金【金50,000,000円】』
『歌舞伎町××エンターテインメント：タイアップ違約金【金80,000,000円】』

送られてきた請求書の合計金額――【二億四千万円】。

「……に、におく……よんせんまん……」
タカシが床に座り込んだまま、白目を剥いて泡を吹きそうになっていた。
「終わった……。国税に金を持っていかれて、警察に追われて、二億以上の借金……。Pさん……オレたち、もう死ぬしかないじゃないですか……首吊るしかないじゃないですか……！」

タカシの涙が、散らかった床にポタポタと落ちていた。
無理もない。二十一歳の若者にとって、この包囲網は世界そのものが崩壊したのと同じだった。

その時だった。

オレの私用スマホの画面に、非通知設定の着信が入った。

オレは深呼吸を一つし、通話ボタンを押してスピーカーにした。

「……もしもし」

受話器の向こうから聞こえてきたのは、安物のウイスキーを氷で割ったような、耳障りでネチネチとした低い笑い声だった。

『――よお、Pちゃん。いい天気だなあ』

佐々木だった。
第2章で、上野の路地裏でオレたちを脅迫し、カオルが雇った神崎弁護士の警告書によって排除されたはずの、六本木の半グレブローカー。

『どうよ、Pちゃん。週刊誌の反響は？ ネットのみんな、お前のこと大絶賛してるぜ？ “世紀の大犯罪者”ってな！ ギャハハハハ！』

「……佐々木さん。あなたが仕組んだことですか」
オレは努めて冷静に問いかけた。

『人聞きの悪いこと言うなよ。俺はただ、お前らみたいな生意気な素人に、夜の街の本当のルールを教えてやってるだけだ。
大手芸能プロダクションの『ライジング』って知ってるだろ？ あそこの社長と俺は昔からの兄弟分でよ。
あいつら、お前らのアングラBreakingDownの利権を丸ごと欲しがってたんだよ。
だから、ちょっと小娘に五十万握らせて、でっち上げのシナリオを読ませて、国税にタレコミを入れてやったのさ』

佐々木の言葉は、悪びれる様子すら微塵もなかった。
それは、弱者をいたぶり、食い物にして生きてきた裏社会の寄生虫特有の、純粋な悪意の結晶だった。

『いいか、Pちゃん。お前に残された道は一つだけだ。
今すぐうちの事務所に来て、チャンネルの全著作権と、サロンの運営権を『ライジング』に無償譲渡する契約書にハンコを押せ。
そうすりゃ、あの小娘に「勘違いでした」って警察に言わせて、週刊誌にも訂正記事を出させてやる。
違約金の二億も、俺たちが肩代わりしてやるよ。
……今日の夜九時までだ。来なかったら、本当にお前の田舎の実家に火がつくぜ？』

プツンッ。
一方的に電話が切れた。

静まり返ったオフィス。
窓の外には、すでにカメラを構えた数人の迷惑系YouTuberたちが、ビルのエントランスに群がり始めているのが見えた。

金は奪われた。社会的信用は地に堕ちた。
仲間は絶望に震え、敵は逃げ場のない罠を張り巡らせて待っている。

だが――。
散らかった書類を踏みしめながら立ち上がったオレの瞳の奥には、恐怖など一欠片も残っていなかった。

オレは机の引き出しから、古いUSBメモリを一本、取り出した。
そこには、昼間の会社で培ったオレのギーク魂が仕掛けた、誰にも知られていない「絶対の防壁」が眠っていた。
