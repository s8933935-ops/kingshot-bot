# 携帯小説『アングラ・バカロード』
## 第2章：売れたぶんだけ、逃げられない
### 【第9話】契約書は拍手しない

---

#### ［１：八百人の会員と、重たい固定費］

二月下旬。
上野の雑居ビルに借りた、家賃九万五千円の小さなワンルーム。
オレ――田中智裕は、デスクの上で電卓を激しく叩いていた。

YouTubeのアドセンス広告収入は、冬の規約改定に伴う審査基準の厳格化により、前月の半分以下に落ち込んでいた。
夜職や歓楽街を扱う動画は、どれだけモザイクをかけようが、広告単価が極端に低く抑えられる「制限付き配信」の対象になりやすい。

そこでオレたちが始めたのが、外部の会員制プラットフォームを利用した有料サロン『アングラ・ラボ』だった。
月額会費：千九百八十円。

「……現在の会員数は、八百十二人です」

オレは手帳の収支表を見つめた。
月間の売上高は、約百六十万円。
数字だけを見れば、手取り二十一万の会社員だったオレにとって、決して小さな金額ではない。
だが――その内訳は、夢のような「不労所得」とは程遠かった。

```
［ 月間 収支内訳（会員800人ベース） ］
・売上高（1,980円×812人）：     1,607,760円
・決済代行手数料（8%）：           128,620円
・ストリーミング配信サーバー費：   350,000円
・事務所賃料・光熱費：             130,000円
・定期出演料（キャスト3名分）：    450,000円
・タカシ撮影・編集委託費：         300,000円
・機材保守・消耗品・雑費：         120,000円
━━━━━━━━━━━━━━━━━━━━━━━━━━━
差引残高（手元資金）：             129,140円
```

残る利益は、わずか十二万九千円。
ここからオレ自身の報酬を取り、税金をプールすれば、手元に残る金はほぼゼロに近い。

「……全然、余裕がないな」
オレはため息を吐いた。
少しでも会員数が減れば、即座に赤字に転落する綱渡り。
機材が壊れても買い替えられず、新しい大型企画を打つ余裕もない。
小さくまとまったまま、じり貧で消耗していく恐怖。

そこに現れたのが――制作会社『メディアルート』のプロデューサー・佐々木だった。

---

#### ［２：六本木の会議室、差し出された契約書］

午後三時。
六本木のガラス張りのオフィスビル。
白を基調とした会議室のテーブルの上に、厚さ一センチの契約書が置かれていた。

「いやあ、Pさん、カオルさん。いつも動画、楽しく拝見してますよ」

テーブルの向かい側に座っていた佐々木は、三十代半ばの、仕立ての良いネイビーのスーツを着こなした男だった。
物腰は柔らかく、笑顔も爽やかだった。
だが――その細められた瞳の奥には、数字と利益だけを冷徹に計算する、現代のデジタルメディアプロデューサー特有の乾いた光が宿っていた。

「単刀直入に申し上げます。弊社の配信ネットワークと提携して、番組の規模を一気に拡大しませんか？」

佐々木はタブレットを操作し、華やかなスライドを提示した。

「現在の八百人という会員数は、個人運営としては立派です。ですが、広告展開もなしにこれ以上のオーガニック（自然流入）を期待するのは難しい。
弊社がスタジオの手配費用、特注美術セットの製作費、そして宣伝広告費として【一千五百万円】を一括で出資します。
弊社の提携インフルエンサーとの大型コラボフェスを仕掛ければ、会員数は一気に五千人、一万人へと跳ね上がりますよ」

タカシが隣で、ゴクリと唾を飲み込む音が聞こえた。
一千五百万円。
自分たちの力だけでは、何年かかっても集められない巨大な軍資金。

だが、カオルは眉一つ動かさず、机の上の契約書を指先で手元に引き寄せた。

「……うまい話の裏には、必ず代償があるわ。
佐々木さん。契約の条件を見せてもらえるかしら」

---

#### ［３：拍手しない文字］

カオルは老眼鏡をかけ、契約書の条文を一行ずつ、指でなぞりながら読み進めていった。
吉原で何十回もの店舗契約や移籍トラブルをくぐり抜けてきた、プロの商人の目が光る。

「……第7条、納品義務とスケジュール」
カオルが顔を上げた。
「隔週での大型特番の納品。公開日の遅延が発生した場合、一回につき【三百万円】の違約金。
第12条、撮影素材の二次利用権。弊社は収録された全未編集素材を、プロモーションおよび関連番組において無償で自由に編集・公開できる権利を有する。
第15条、企画の中止条項。乙（P-PROJECT）の都合により企画が中止された場合、甲が投じた制作準備費用の全額を即日一括で返金するものとする……」

カオルは契約書を机の上に置いた。
その音は、冷たく響いた。

「随分と、一方的な条件ね。
もし出演するキャストが体調を崩したり、現場でトラブルが起きて撮影が止まったら、
アタシたちが全部の負債を背負うことになるじゃない」

佐々木は穏やかな笑顔を崩さなかった。
「カオルさん。ビジネスですから。
一千五百万円というリスクマネーを動かす以上、配信日の確定と素材の権利を担保していただくのは当然の条件です。
もちろん――順調に会員数が伸びて黒字化すれば、売上の40%は御社にレベニューシェアとして毎月入ります。
月収数百万円なんて、あっという間ですよ」

会議室に、沈黙が落ちた。

タカシは明らかに乗り気だった。
「Pさん……これ受ければ、オレたちの機材も全部最新にできるし、借金も一気に返せますよ……」

カオルはオレの目を見つめていた。
彼女は、この契約の危険性を誰よりも分かっていた。
だが同時に――現在の自前サロンのギリギリの台所事情も、オレが昼間の会社員を続けながら深夜まで編集作業に追われ、過労で倒れかけている現実も、知っていたのだ。

「……P。決めるのはアンタよ」
カオルは静かに言った。
「この契約書はね、拍手もしてくれなきゃ、アンタの事情も聞いてくれないわ。
一度サインしたら、何があってもこの紙に書かれたルール通りに首を絞められる。
それでも……やるの？」

オレは契約書の文字を見つめた。
恐怖はあった。
だが、それ以上に――「もっと大きな舞台で、もっと多くの人間に見てもらいたい」という、抑えきれない渇望が、オレの腹の底で渦巻いていた。

「……佐々木さん」
オレはペンを握った。
「第12条の素材利用権、ここだけ修正してください。
『出演者の名誉を傷つける恐れのある未公開素材の公開には、乙の事前の書面による同意を必要とする』。
この一文を入れてもらえるなら……契約します」

佐々木は一瞬だけ目を細め、やがて満足げに頷いた。
「分かりました。その条件、呑みましょう」

カリカリと、署名捺印の音が響いた。
拍手のない契約書の上に、オレたちの未来が縛り付けられた瞬間だった。

手に入れたのは、一千五百万円の翼。
だがそれは、一度飛び立てば二度と降りることのできない、逃げ場のない空中戦への招待状だった。
