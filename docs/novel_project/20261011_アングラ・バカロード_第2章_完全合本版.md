吉原からの帰り道。

明らかに、ヤクザとも堅気とも違う――六本木や歌舞伎町を根城にする、現代の「半グレ（準暴力団）ブローカー」の風貌だった。

中央の男が、人懐っこい笑みを浮かべながら近づいてきた。

「……ど、どちら様でしょうか」
オレはタカシを背後に庇いながら、後ずさりした。

「固いこと言うなよ。俺は○○興業の役員やってる、佐々木ってモンだ。いやあ、見たぜ吉原の動画。最高だったなあ！ 天才だよ、Pちゃん」

佐々木は馴れ馴れしくオレの肩に腕を回してきた。

タカシが息を呑んだ。

佐々木の背後に立っていた大柄な男が、一歩前に出た。
その手首には、大きなタトゥーが彫られていた。
「おい小僧。口の利き方に気をつけろや。誰のおかげでこの街でカメラ回せてると思ってんだ？」

空気が、一瞬で凍りついた。
歌舞伎町で黒服に胸ぐらを掴まれた時とは、次元が違っていた。

「……申し訳ありません」
オレは冷や汗を流しながら、頭を下げた。

佐々木はフッと口角を上げ、オレの頬をペチペチと軽く叩いた。

一万人集まれば、月商二千万円。二万人なら、四千万円だ」

オレはマーカーを置き、カオルとタカシの顔を真っ直ぐに見据えた。

「これが――オレが考案した【二階建てファネル・アーキテクチャ】です。
表のYouTubeで誰からも文句を言われないバカ騒ぎをやって大衆を惹きつけ、裏の会員制要塞で本物のアングラ経済を回す。
GoogleのAIに殺されるんじゃない。Googleのトラフィックを、オレたちの城の燃料として貪り食ってやるんです」

カオルが、目を見張っていた。
タカシが、口を半開きにして震えていた。

絶望の淵で、オタクの脳髄が弾き出したのは、プラットフォームの支配を逆手に取る、凶悪無比な「規約ハックの青写真」だった。

カオルの唇が、ゆっくりと弧を描いた。
その瞳に、再び獰猛な女帝の輝きが戻っていた。

「……最高じゃない、ハゲ。
いいわ。裏の決済システムと法務の整備、アタシが二日で完璧に仕上げてあげる。
アンタはその『表のバカ騒ぎ』のコンテンツを、今すぐ作りなさい」

死刑宣告の朝。
それは、誰も想像し得なかった「月商一億円の巨大要塞」が爆誕するための、産声の瞬間に変わった。

# 携帯小説『アングラ・バカロード』
## 第2章：二階建ての城と、札束の窒息
### 【第4話】発明『二階建てファネル』と月商1億円（超濃密・文庫完全版）

#### ［１：要塞の建設、徹夜のサーバー構築］

カチカチ、カチカチ……。
タ――ン！

上野のオフィス。静寂を切り裂くエンターキーの音が、夜明けの空に響き渡った。

オレは充血した目をこすりながら、自作スクリプトのデプロイ（配備）状況を確認した。
AWS（Amazon Web Services）上に構築された、堅牢な独立ストリーミングサーバー。
コンテンツ配信ネットワーク（CDN）にはCloudflareを噛ませ、DDoS攻撃や突発的な数十万アクセスのスパイクにも耐えうるスケーラブルな構成。

そして、そのバックエンドには――カオルがわずか四十八時間で引っ張ってきた、海外の独立系決済ゲートウェイが完璧に組み込まれていた。

「……決済のテスト、通ったわよ」

ソファから立ち上がったカオルが、スマホの画面をオレに見せた。
テストアカウントでの1,980円の課金処理が、コンマ数秒で完了し、決済完了メールが飛んでいた。

日本の主要なクレジットカード会社や国内決済代行会社は、アングラ系や夜職系のコンテンツに対して極めて臆病だ。規約一つでアカウントを凍結されるリスクがある。
だがカオルが押さえてきたのは、マルタ共和国とシンガポールに拠点を置く、世界中のクローズド会員制サロンや海外メディアが利用する「審査厳格・凍結耐性最高峰」の国際決済ネットワークだった。

「法務のリーガルチェックも完璧よ」
カオルは誇らしげに胸を張った。
「神崎先生と水野先生が、利用規約、プライバシーポリシー、特定商取引法に基づく表記をすべて固めたわ。表のYouTubeは完全にクリーンな宣伝媒体。裏の有料サロンは、成人確認を徹底した完全招待制の閉鎖空間。法律的にも、プラットフォームの規約的にも、誰にも手出しできない『治外法権の要塞』が完成したわよ」

「ありがとうございます、カオルさん。……さあ、タカシ。表の弾を撃ち込むぞ」

「うっす！ 準備、完璧にできてます！」
タカシがモニターの前に陣取り、YouTubeの公開ボタンにカーソルを合わせた。

表のYouTube動画のタイトルは――。
『【爆笑】歌舞伎町の超高級キャバクラで「一番注文されない激マズ激辛カクテル」を頼んだらおっさんが泡吹いて気絶したwww』

徹底的にクリーンだった。
性的な要素はゼロ。暴力もゼロ。
映っているのは、豪華な店内で、綺麗なドレスを着た女の子たちに囲まれながら、激辛カクテルを一気飲みして顔面を真っ赤にし、テーブルから転がり落ちて「からいぃぃぃ！ 水ぅぅぅ！」と情けなく叫ぶ、中年ピエロ・Pの無様な姿だけ。

地上波のゴールデンタイムのバラエティ番組と何ら変わらない、誰が見ても笑える健全なコメディ。
Googleの検閲AIの審査は――わずか三分で【緑色のドルマーク】を弾き出した。
広告制限ゼロ。違反警告ゼロ。完全なセーフ判定。

だが――その動画のラスト十五秒。
激辛で悶絶するPの姿がフェードアウトした瞬間、画面は漆黒に染まり、重厚なドラムロールとともに、深紅の文字が浮かび上がる仕掛けになっていた。

```
――【警告：ここから先は、地上波では絶対に流せません】

歌舞伎町の裏帳簿、ナンバーワンキャストが語る「枕営業の真実と狂気」、
そして、夜の街を牛耳るフィクサーへの潜入ノーカット完全版は――
公式プレミアム要塞【P-PROJECT VIP CLUB】にて独占公開中。

▼完全版を見る（概要欄・固定コメントのURLへ）
```

午前八時。
再生ボタンが、世界に向けて解き放たれた。

#### ［２：鳴り止まない決済音、奇跡のメガバズ］

その動画は、まるで干上がった砂漠に注がれた濁流のように、瞬く間にネットの海を呑み込んでいった。

表の動画が圧倒的にクリーンで健全だったため、YouTubeのおすすめアルゴリズムが猛烈な勢いで回転を始めたのだ。
中高生から主婦、サラリーマンに至るまで、幅広い層のタイムラインに動画がおすすめ表示され、再生回数は公開からわずか六時間で【二百万回】を突破。
急上昇ランキングの頂点へと一気に駆け上がった。

そして――。
その二百万人のうちの「最も好奇心の強い層」が、概要欄のリンクをクリックした。

オフィスの大型モニターに表示されていた、独自サーバーのリアルタイム監視ダッシュボード。
そこに刻まれる数字が、目に見えるスピードで狂ったように跳ね上がっていった。

『同時アクセス数：12,400人』
『同時アクセス数：48,900人』
『同時アクセス数：112,000人』

ピロン。
ピロン。ピロン。
ピロロロロロロロロロロンッ……！

管理画面の成約通知音が、最初は数秒おきに、やがては壊れたパチンコ台のように鳴り止まない連打の音へと変わった。

『新規会員登録：月額1,980円』
『新規会員登録：月額1,980円』
『新規会員登録：月額1,980円』
『新規会員登録：月額1,980円』

「う、うわああああああああっ！！」
タカシが頭を抱えて絶叫した。
「止まらねえ！ 決済が止まらねえっす！！ 一分間に五百人ずつ会員が増えてる！！ サーバー落ちるぞ、Pさん！！」

「落ちない！ オレが組んだAWSのオートスケーリングを舐めるな！」
オレはキーボードを叩き、サーバーのインスタンス数を瞬時に三十二台へと引き上げた。
負荷分散は完璧だった。
どんなにアクセスが殺到しても、画面は一ミリも止まらない。ユーザーはクレジットカード番号を入力し、吸い込まれるように月額会員へと登録していく。

公開から二十四時間後。
ダッシュボードに表示された【アクティブ有料会員数】の数字は――。

『会員数：35,420人』

「さ、さんまんごせん……？」
タカシが声を失い、膝から崩れ落ちた。

月額1,980円×35,420人。
月間のサブスクリプション売上高――【70,131,600円】。

Googleのアドセンス広告収入ではない。
誰の検閲も受けず、誰にもピンハネされない、オレたちの法人口座に毎月自動で着金し続ける、純度100%の継続課金収入が、一撃で七千万円を超えたのだ。

さらに、表のYouTube動画の広告収入（緑マーク復活）で一千五百万円。
プレミアム会員向けの限定グッズ販売と、スポンサー企業からの正規タイアップ費で二千万円。

合計月商――【一億五百万円】。

上野の小さなオフィスに、静寂が訪れた。
モニターの青白い光が、三人の顔を照らしていた。
それは、誰もが夢見ながら、誰も到達できなかった、アングラコンテンツビジネスの「頂点（テッペン）」の数字だった。

#### ［３：札束の海と、ピエロの選択］

「……一億よ」

カオルが震える指でワイングラスを持ち上げ、乾いた声で呟いた。
その瞳には、さすがの女帝も隠しきれない動揺と、底知れぬ興奮が滲んでいた。

「吉原で五年間、泥水すすって稼いできたアタシの全財産が……たった一ヶ月で入ってきたわ。
P。アンタ、本当に化物ね。歴史を作ったわよ」

「Pさん……！ これでオレたち、億万長者っすよ！」
タカシが涙を流しながら笑った。
「六本木のタワマンに住みましょう！ ポルシェ買いましょう！ 銀座のクラブで豪遊しましょうよ！ もう誰にも頭下げる必要なんてないんすよ！！」

タカシの言葉は、世の成金たちの当たり前の反応だった。
月商一億円。手元のキャッシュは山のようにある。
会社を辞め、高級車を乗り回し、贅沢の限りを尽くして暮らす権利が、オレにはあった。

だが――。

オレは、静かに首を横に振った。

「タワマンも、ポルシェも、銀座のクラブも……一円も要りません」

「え……？」
タカシがぽかんと口を開けた。
カオルもまた、怪訝そうに眉をひそめてオレを見つめた。

「あんた、何を言ってるの？ この一億円の山を目の前にして、何も買わない気？」

「買いますよ」
オレは立ち上がり、デスクの引き出しから、一枚の巨大な設計図を取り出してテーブルの上に広げた。

そこには、精密な三次元CADで描かれた、巨大な建造物の図面が引かれていた。

「オレが買うのは……これです」

設計図の中央に描かれていたのは、見たこともない異様な構造物だった。
幅四メートル、奥行き三メートル、高さ二・五メートル。
厚さ八十ミリの特注強化アクリルパネルで四方を囲まれた、巨大な直方体。
底面には業務用急速循環ボイラーが直結され、上部には可動式の吊り下げ式クレーンが設置されている。

図面の最上部に書かれた製品名を見て、カオルとタカシの呼吸が止まった。

『特注強化アクリル製・油圧式急速昇降型　巨大熱湯水槽（耐熱85℃仕様）』
『概算見積金額：55,000,000円（設置・配管工事費込）』

「……ご、ごせんごひゃくまん……！？」
タカシの顎が外れそうになった。
「な、なんすかこれ！？ ね、熱湯水槽……！？ なんでそんなものに五千万も使うんすか！？」

「足りないんだよ、タカシ」
オレの瞳の奥に、深海のように昏く、だが熱狂的な炎が灯っていた。

「画面の向こうの視聴者は、オレたちの二階建てファネルに拍手を送ってるんじゃない。
彼らが金を払っているのは――『安全地帯から見る、命懸けのピエロの無様な転落』だ。
オレが小奇麗なタワマンに住んで、美味い飯を食って太った瞬間、この魔法は全部解ける。
ピエロが生き残る道は……ただ一つ。
誰よりも無様に、誰よりも熱い地獄へ、自ら笑顔で飛び込み続けることだけだ」

オレは設計図の「熱湯水槽」の文字を、人差し指で強く叩いた。

「この特注水槽を、千葉の廃倉庫に特設スタジオとして建設する。
そして――日本中のアングラな猛者たち、喧嘩自慢、夜の街の荒くれ者たちを集めるんだ。
負けた奴は、この四十八度の熱湯水槽に真っ逆さまに叩き落とされる。
ルール無用の、アングラ・バカタール・格闘エンターテインメント――！」

カオルが、息を呑んでオレを見つめていた。
その瞳には、恐怖と、戦慄と、そして狂気的な歓喜が入り混じっていた。

「……アンタ、本物の狂人ね」
カオルはグラスを机に叩きつけ、不敵に笑った。
「いいわ。最高よ。五千五百万の水槽、アタシが明日キャッシュで一括発注してあげる。
とことん付き合ってあげるわよ、アンタの地獄の道化芝居に！」

月商一億円を手に入れた男たちが選んだのは、安寧の成功ではなかった。
すべてを投げ打ち、さらなる狂気と暴力の渦巻く「熱湯と格闘の新世界」へのダイブ。

アングラ・バカロードは、ここから更なる次元の狂乱へと突入していこうとしていた。
