# 携帯小説『アングラ・バカロード』
## 第1章：三人で作る嘘のない嘘
### 【第8話】名前を出すのは誰の仕事か

---

#### ［１：店長の計算と、守るべき境界線］

一月上旬。寒風が吹きすさぶ吉原の裏通り。
『桃源郷』の事務所で、初老の店長が腕組みをしながら、煙草の煙を吐き出していた。

「……Pさんよ。動画の反響、悪くねえよ」
店長は机の上のノートPCの画面をトントンと叩いた。
カオルのインタビュー動画の再生数は、公開から二週間で八万回に達していた。

「だけどな、動画の概要欄見ても、うちの店名が一文字も入ってねえじゃねえか。
『都内某所の高級店』じゃ、客がどこに電話すりゃいいか分からねえだろ。
せっかく撮影許可出してやったんだからよ、店のホームページのリンクと電話番号、デカデカと貼ってくれよ。そうすりゃ、うちもカオルももっと儲かるんだからよ」

店長の要求は、ビジネスとして至極当然だった。
店にとって、YouTubeに出る唯一のメリットは「新規客の獲得」だ。
場所も名前も伏せたままでは、店側にとってはボランティアで場所を貸したのと変わらない。

「それは……」
オレ――田中智裕は言葉に詰まった。
カオルとの約束は「店名非公開」。
だが、店長を納得させられなければ、今後の撮影はすべて打ち切りになる。

その時、横に座っていたカオルが、すっと手を挙げた。

「店長。店の電話番号を直で貼るのはダメよ」
カオルは静かに、だが有無を言わさぬ口調で言った。

「ネットの不特定多数に店の電話を晒したら、冷やかしやイタズラ電話で受付の業務がパンクするわ。
うちに来るような本当の上客は、YouTubeの概要欄から直電なんてかけてこない。
代わりに――アタシの公式LINEの予約窓口だけ、リンクを載せなさい」

「LINE窓口……？」店長が眉をひそめた。

「ええ。アタシが事前にメッセージでやり取りして、身元とマナーを確認できたお客様だけを、店長に取り次ぐわ。
仕事用の源氏名『カオル』と、アタシが管理する予約導線だけを公開する。
店の外観や住所、他の女の子の情報は、一切出さない。
それなら、店にとっても優良な新規客が増えるし、店の安全も守られるでしょう？」

見事な落とし所だった。
プライバシーの保護と、現実の集客ビジネス。
その二つを両立させる境界線を、カオル自身が「自分の責任」において引き直したのだ。

店長は唸り声を上げ、やがて渋々頷いた。
「……分かったよ。カオルがそこまで仕切るなら、任せる」

#### ［２：八万四千円の分配］

その夜。
上野のガード下にある、煤けた焼き鳥屋のカウンター。
赤提灯の明かりの下で、オレとタカシ、そして私服のニットに着替えたカオルの三人が並んで座っていた。

オレはノートPCの画面を二重に確認し、テーブルの上に三つの白い封筒を置いた。

「今月の収支報告です」
オレは手帳を広げた。

```
［ 12月度 チャンネル収支報告 ］
・YouTubeアドセンス収益：     148,000円
・動画制作経費（機材・交通費）：  42,000円
・スタジオ・飲食実費：            22,000円
━━━━━━━━━━━━━━━━━━━━━━━━━━━
純利益（差引残高）：              84,000円
```

「……黒字だ」
タカシが息を呑んだ。

たった八万四千円。
世の有名YouTuberたちが稼ぎ出す億単位の金に比べれば、鼻で笑われるような端金（はしたがね）だ。
だが――泥水をすすり、借金を重ね、電気が止まる恐怖の中で足掻いてきたオレたちにとって、
それは誰の顔にも泥を塗らず、誰も傷つけずに生み出した、純度100%の「本物の利益」だった。

「分配です」
オレは封筒を二人に差し出した。
「タカシ君に、撮影・編集の歩合として三万円。
カオルさんに、出演料と企画協力費として三万円。
残りの二万四千円は、次回の機材費と予備費としてプールします」

カオルは封筒を一瞥し、ふっと目を細めた。
「P。アタシの分はいいわよ。まだ番組が軌道に乗るまで、プール金に回しなさいな。
アタシは本業で稼いでるんだから、こんな小銭、今すぐ必要ないわ」

「ダメです」
オレは首を強く横に振った。

「カオルさん。これは、あなたの時間と知恵に対する正当な対価です。
誰かの善意やタダ働きに甘えた瞬間、この番組は腐る。
少なくても、稼げたぶんだけはきっちり分ける。
それができないなら……オレはプロデューサーを名乗る資格なんてありません」

カオルは驚いたようにオレの顔を見つめた。
そして、小さくため息を吐くと、封筒をバッグの中へと滑り込ませた。

「……頑固ね、アンタ。でも……ありがとう。仕事として受け取るわ」

タカシもまた、三万円の入った封筒を両手で強く握りしめていた。
「……Pさん。オレ、今月のアコムの利息、これで払えます……。
自分の撮った動画で金が稼げたの、生まれて初めてっすよ……」
タカシの瞳に、うっすらと涙が浮かんでいた。

#### ［３：カメラの外の夜］

「すみませーん、ホッピーの白セット一つ！ あと、ももと皮をタレで！」

オレが店員に声をかけると、カオルが呆れたように笑った。
「アンタ、初対面の時はあんなにオドオドしてたくせに、大衆居酒屋だと妙に手慣れてるわね」

「十三年間、会社の冴えないおじさんやってますからね。赤提灯の注文だけはプロ級ですよ」

タカシが吹き出した。
「Pさん、マジでそれ威張ることじゃないっすよ！」

煙と油の匂いが立ち込める狭いカウンター。
そこには、カメラのレンズも、マイクも、台本も存在しなかった。
誰も演じていない。誰も数字を追っていない。

カオルが、串から外した焼き鳥をつまみながら、ふと呟いた。
「……昔ね。二十代前半の頃、実家の父親が倒れて、昼間の事務のバイトだけじゃ入院費が払えなくなって……
初めて夜の街に入った日のこと、思い出しちゃったわ」

「そうだったんですか」

「うん。最初の店はね、歌舞伎町の汚いスナックだった。
毎日、酔っ払った客に怒鳴られて、泣きながらトイレ掃除して……
『アタシの人生、こんなところで終わるのかな』って、毎晩始発電車の中で思ってた」

カオルは生ビールのジョッキを傾け、静かに微笑んだ。
「だからね……あんな風に、真っ直ぐにアタシたちの話を聞いてくれる人がいるってだけで……
ちょっとだけ、救われた気がしたのよ」

オレは何も言えず、黙って自分のジョッキを見つめていた。
気の利いた励ましも、大層な名言も、オレの口からは出てこなかった。
ただ、冷たいビールの泡が弾ける音だけが、心地よく耳に届いていた。

タカシが、スマホを取り出そうとして手を止めた。
「……これ、撮らなくていいんすよね？」

「当たり前だろ」
オレは笑った。
「全部をカメラに晒してたら、人間、心がすり減って死んじまうよ。
カメラの外に、ちゃんと自分の生活があるからこそ……カメラの前で、本気で笑えるんだ」

夜の街の片隅。
三十九歳の冴えない会社員と、夜の街を生きる女帝と、借金を抱えた若者。
打算と偶然から始まった三人の奇妙な繋がりが、
初めて一つの「対等なチーム」として息づき始めた、冬の静かな夜だった。
