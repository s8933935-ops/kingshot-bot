# 携帯小説『アングラ・バカロード』
## 第1章：三人で作る嘘のない嘘
### 【第5話】カメラの向こうの借金

---

#### ［１：御徒町の純喫茶、二十一歳の請求書］

十二月中旬。
御徒町駅のガード下、昭和の香りを残す純喫茶『丘』の地下フロア。
赤いベロアのソファの向かい側に座っていたのは、黒いオーバーサイズのパーカーを着た二十一歳の若者――タカシだった。

「……で、これがオレのポートフォリオっす」

タカシは画面のバキバキに割れたスマートフォンをテーブルに置き、過去に手がけたというインフルエンサーの切り抜き動画や、イベント撮影のダイジェスト映像を見せてきた。
カメラワークは安定しており、音の処理やテロップのタイミングも的確だった。
一人でアクションカメラを胸に括り付け、手ブレで画面酔いするような動画を撮っていたオレとは、明らかに技術の基礎が違っていた。

「Pさんの動画、見ましたよ」
タカシはアイスコーヒーのストローを回しながら、悪びれずに言った。
「湯島のガールズバーのやつ、死ぬほど笑いました。でも……一人で胸にカメラつけて撮ってるから、Pさんの肝心の情けないリアクションが半分フレームアウトしてるんすよ。カメラマンが一人外側にいて、引きの絵と寄りの絵を切り替えなきゃ、エンタメとして勿体無さすぎます」

「……そう、なんだよな」
オレは頷いた。
カオルとの取材撮影が決まったものの、一人で被写体とカメラマンを同時にこなす限界は、痛いほど感じていた。

「オレがカメラ回しますよ」
タカシは身を乗り出してきた。
だが、その次の瞬間、彼の口から出た言葉は、ネットの甘い「仲間募集」のノリとは違っていた。

「ただし――撮影一本につき、機材費込みで【一万五千円】ください。編集の手伝いも入れるなら、プラス一万円。交通費は別で」

オレは思わず喉を詰まらせた。
「え……？ お金、取るの？」

喉元まで、「同じ底辺の仲間として、チャンネルが伸びるまで一緒に夢を見てくれないか」という甘えた言葉が出かかった。
だが、タカシの冷ややかな、だが切迫した瞳を見た瞬間、その言葉は喉の奥に引っ込んだ。

---

#### ［２：テーブルの上に広げられた負債］

「タカシ君。君、もしかして……」

タカシは自嘲するようにフッと笑い、パーカーのポケットから折りたたまれた明細票の束を取り出して、テーブルの上に広げた。

『アコム　ご請求金額：480,000円』
『プロミス　お借入残高：620,000円』
『学生ローン　残高：350,000円』
『友人への借入メモ：850,000円』
合計――二百三十万円。

「大学中退して、怪しい副業グループに騙されて情報商材買わされて、このザマっすよ」
タカシは紙ナプキンをいじりながら、吐き捨てるように言った。

「毎月、利息の支払いだけで五万飛ぶんすよ。日雇いのバイト代なんて右から左へ消える。
オレは暇つぶしでYouTubeやりたいわけじゃないんです。金が欲しいんです。
Pさんの動画が面白いと思ったから組みたい。でも、タダ働きしてたらオレ、来月にはネカフェ代も払えなくなって野垂れ死ぬんすよ」

身につまされる現実だった。
オレは自分の財布の中身を思い出した。
所持金千二百円。クレジットカードの利用可能枠ゼロ。
給料の前借りで手に入れた十万円も、カオルの店の撮影費用として消える予定だ。

オレ自身、カードの限度額いっぱいに借金を背負い、電気代すら払えなくなって泣いていた身だ。
そのオレが、同じように借金に追われて必死に生きようとしている二十一歳の若者に向かって、「仲間だからタダで手伝ってくれ」などと、どの口が言えるというのか。

オレは手帳を開き、新しいページにペンを走らせた。

```
［ 吉原取材・第1回 制作予算案 ］
・店舗撮影費（カオル指名料）：  50,000円（※取材特別料金）
・カメラマン人件費（タカシ）：  15,000円
・編集補助費：                  10,000円
・機材運搬・交通費：             5,000円
・予備費（飲食・雑費）：         5,000円
━━━━━━━━━━━━━━━━━━━━━━━━━━━
合　計：                        85,000円
```

「……分かった。一本二万五千円、払うよ」
オレは手帳をタカシに見せた。

タカシが目を丸くした。
「……マジっすか？ Pさんだって、金ないんでしょ？」

「ないよ。今月の生活費、全部突っ込んでる」
オレは苦笑いした。
「でも、人の時間をタダで買い叩いて作った動画なんて、絶対にいいものにならない。オレたちは仕事として、この番組を作るんだ」

タカシの表情から、尖った警戒心がすっと抜けた。
彼は紙ナプキンを置き、深く頭を下げた。
「……ありがとうございます。その代わり、絶対にいい画、撮りますから」

---

#### ［３：最初の編集案に残った毒］

「で、Pさん。企画の構成案なんですけど」
タカシはスマホを取り出し、メモ帳の画面を見せてきた。

「吉原の高級店って、ネットじゃみんな知りたがってるじゃないですか。
だから、店の外観の看板とか、待合室の奥にある歴代ナンバーワンの写真立てとか、さりげなくカメラをパンして映しときましょうよ。
『吉原の有名店○○に潜入！』ってサムネに書けば、再生数、一発で十万回は超えますよ」

タカシの提案は、YouTubeのアルゴリズムを知る若者特有の、極めて合理的で「数字の取れる」アイデアだった。
だが――オレの脳裏に、カオルと交わしたあの約束の紙が浮かんだ。

〈一つ、店名および場所を特定できる看板・外観は一切映さないこと〉

「……ダメだ、タカシ」
オレは首を横に振った。

「え？ なんでっすか？ 看板くらい、ちょっと映ったって誰も気にしないっすよ」

「カオルさんと約束したんだ。店名も場所も絶対に出さないって。
相手の身元を売り飛ばして取る十万再生なんて、オレはいらない」

タカシは不満そうに口を尖らせた。
「……真面目すぎますよ、Pさん。そんな綺麗事言ってたら、いつまで経っても稼げないっすよ」

「綺麗事じゃない」
オレはタカシの目を真っ直ぐに見つめた。
「オレたちが売るのは、他人の秘密じゃない。オレ自身の無様さだ。
カメラの向こうにいる女の子の人生を脅かしてまで作る動画なら……オレは最初からやらない」

タカシは何か言いかけようとして、口を閉じた。
そして、小さくため息を吐いた。

「……分かりましたよ。じゃあ、店の外観は一切抜かずに、部屋の中のPさんの顔のアップだけで勝負しましょう。その代わり……めちゃくちゃ情けない顔、撮りますからね」

「望むところだ」

借金を抱えた二人の男が、初めて「制作費を払う責任」と「越えてはならない一線」を共有した瞬間だった。
安易な数字の誘惑と、倫理の境界線。
その危ういバランスの上に、オレたちの小さな番組が、最初の一歩を踏み出そうとしていた。
