# 🏭 Satisfactory v1.0 攻略案内 Discord Bot 取扱説明書
**〜 FICSIT 工場技術顧問団 〜**

Satisfactory（サティスファクトリ）v1.0 正式版に対応したDiscord攻略案内チャットボットです。
公式ゲーム内データ（100%確定レシピ）とYouTubeトップビルダーの解説知見（該当秒数直結リンク）を搭載しています。

---

## 🚀 1. 起動と停止（クリック一発）

- **起動方法**: デスクトップの **「Satisfactory_Bot」ショートカットをダブルクリック** してください。黒い画面が開き、自動でDiscordに接続されます。
- **停止方法**: 起動中の黒い画面を閉じるか、フォルダ内の `Satisfactory_Bot_停止.bat` を実行してください。

---

## 💬 2. 質問・チャットの使い方

### ① 普通にチャットで話しかける（3通り）
1. **専用チャンネルで話す（一番おすすめ・メンション不要）**
   - チャンネル名に **`bot`**, **`攻略`**, **`質問`**, **`satisfactory`** のいずれかが入っているチャンネル（例: `#satisfactory-攻略`）なら、**メンション不要で普通の日本語チャットに全自動返信** します。
2. **Botに「@メンション」して話しかける**
   - どのチャンネルでも `@サティスファクトリ回答BOT 鉄板のレシピ教えて` とメンションすれば答えてくれます。
3. **Botの発言に「返信（リプライ）」して会話を続ける**
   - 「じゃあ代替レシピはどれが一番おすすめ？」と連続で会話できます。

### ② 📸 スクリーンショット画像診断（おすすめ！）
配管の詰まりや列車信号エラーなど、言葉で説明しにくい時は **ゲーム画面のスクショをDiscordに貼るだけ** でOK！
- `[スクショ貼り付け]` ＋ 「この配管の何がダメで水が止まってる？」
- `[スクショ貼り付け]` ＋ 「列車信号のブロックとパス、この配置で合ってる？」
AIがマシンの稼働ランプ、配管ポンプの揚程、信号の区間境界を直接見て具体的に診断します。

### ③ 🧠 最高峰AI（Claude 3.7）召喚ボタンの仕組み
高度な設計相談や画像診断の際、勝手に枠を消費せず **確認ボタン** が届きます：
> ⚠️ この相談は高度な推論を要します。**最高峰AI（Claude 3.7 Sonnet）** を召喚しますか？  
> 📊 本日残り利用回数: **29 / 30 回**  
> 【🟢 **はい、最高峰AIを召喚 (残り29回)**】 【⚪ **いいえ、通常チームで回答 (枠温存)**】

- **【はい】**: Claude 3.7 Sonnet が召喚され、深層推論で超高精度の設計回答を生成（枠 -1）。
- **【いいえ】**: 通常チーム（公式DB＋YouTube Tips）が回答（**Claude枠を温存！**）。
- ※単純なレシピ質問はボタンを出さずに公式DBから0秒で即答します。

## ⚡ 3. スラッシュコマンド一覧

チャット欄で `/` を打つと使える便利機能です：

| コマンド | 説明 | 枠消費 |
| :--- | :--- | :--- |
| **`/ask <質問> [画像]`** | 攻略質問や画像診断（難易度に応じて自動判定）。 | 通常は無制限 / 召喚時のみ-1 |
| **`/recipe <アイテム名>`** | 通常・代替レシピ、生産レート、必要機械を表形式で即答。 | **完全無制限 ($0・0秒)** |
| **`/troubleshoot <困りごと>`** | パイプ詰まり、水ループ等のYouTube動画（**該当秒数リンク付き**）を検索。 | **完全無制限 ($0)** |
| **`/memory`** | Botが記憶している工場の現状（長期確定事実、歴史、直近ログ数）を確認。 | **完全無制限 ($0)** |
| **`/limit`** | 本日のClaude残り回数（30回枠）とメンバー別利用内訳を確認。 | **完全無制限 ($0)** |
| **`/reset`** | 会話記憶・工場データバンクを初期化して新しい話題を開始。 | **完全無制限 ($0)** |

## 🧠 4. 人間の脳と同じ「二重記憶システム」

- **短期記憶（直近30ターン）**: 直近の会話を生ログとして毎回専用ファイルに記録。
- **長期記憶（ローリング要約）**: 30ターンを超えた古い会話は、ローカルAI（$0）が裏で自動要約。「現在のTier」「採用した代替レシピ」「建設済み工場」を抽出し、2,500文字以内で永久記憶します。
- ※何日経っても「前作った鉄板工場」などの文脈を覚えていてくれます！

- **最高峰AI (Claude 3.7 Sonnet)**: **2人共有で 1日 30回**（毎朝0時に自動リセット）
- **公式DB検索 / YouTube Tips / 通常チーム**: **完全無制限（使い放題）**
- ※Claude枠が0になってもBotは止まらず、通常チームが無制限で答え続けます。
